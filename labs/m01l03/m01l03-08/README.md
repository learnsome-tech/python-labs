## Goal

You can describe what kind of language Python is, place its origin and the two versus three split in time, read a Python version number, and ask your own interpreter which version, platform and implementation you are running.

In the lesson: That last answer deserves a moment. Python the language is a written specification. The thing you install is a program that implements it, and there is more than one such program. The usual one, and the one you will install next module, is written in the C language and is called C Python, spelled as one word on screen. Others exist: one rewrites your code as it runs and can be far faster on long calculations, another is trimmed to fit a controller with a few kilobytes of memory. They all aim at the same language. Unless you go looking, you are running the standard one.
