## Goal

You can describe what kind of language Python is, place its origin and the two versus three split in time, read a Python version number, and ask your own interpreter which version, platform and implementation you are running.

In the lesson: Look at the three lines on screen. The same name is attached first to a whole number, then to some text, then to a list holding both. In many older languages that is illegal: you promise up front that a name will hold whole numbers, and the translator holds you to it. Python takes the other road. A name is a label, the type belongs to the value the label is attached to, and you may move the label whenever you like. That buys you speed and comfort while writing. It costs you a safety net, because a mistake about types is discovered while the program runs rather than before it starts. Later in this course we come back and put some of that net back.
