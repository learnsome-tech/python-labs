## Goal

You can describe what kind of language Python is, place its origin and the two versus three split in time, read a Python version number, and ask your own interpreter which version, platform and implementation you are running.

In the lesson: Version numbers come in three parts, and the panel spells them out. The first, the major version, changes only for a break in compatibility, which is why it has been three since two thousand and eight. The second, the minor version, goes up for a feature release, and since version three point nine those arrive on a fixed schedule, one every October. The third, the micro version, goes up for a batch of bug fixes, and taking a new micro version is safe. Each feature release is looked after for about five years. So you upgrade because you want something, not because you must.
