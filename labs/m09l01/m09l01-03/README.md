## Goal

You can call a method on a string with the object dot method syntax, explain why a string method returns a new string instead of changing the original, and use upper, lower, capitalize, title and count.

In the lesson: We are using the new object syntax: the object, then a dot, then the method name, then parentheses. It means the method associated with the object's type is applied to that object. This is a special syntax for a function call with an object attached, and many methods take extra parameters between the parentheses as well. Just as a parameter can be replaced by a literal or by any expression, the object a method is bound to may also be given by a literal, a variable name, or any expression that evaluates to the right kind of object. That holds for every method call you will ever write.
