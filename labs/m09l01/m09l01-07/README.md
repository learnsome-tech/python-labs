## Goal

You can call a method on a string with the object dot method syntax, explain why a string method returns a new string instead of changing the original, and use upper, lower, capitalize, title and count.

In the lesson: Python lets you see all the methods bound to an object, and to any object of its type, with the built-in function dir. To see all the string methods, hand dir any string at all, even the empty one. Many of the names in the list start and end with two underscores. Those are methods and pieces of data the interpreter uses internally, and you can ignore them for now. The remaining entries are all user-level methods for strings, and you should be able to spot lower and upper among them. Some are used far more often than others. The screen shows the list shortened, because the real one is long. And remember: the object dot method notation is not a string thing. If seq is a list, seq dot append adds an element to the end of it. If myData is a file, myData dot read returns the entire contents. Same notation, different types.
