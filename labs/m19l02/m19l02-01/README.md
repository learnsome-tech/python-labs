## Goal

You can turn a build-a-list loop into a list comprehension with an optional filter, write dictionary and set comprehensions, and say when a plain loop is the clearer choice.

In the lesson: By now you have written this loop many times. Make an empty list. Loop over something. Append one value per item. Use the list. Four lines, and only one of them says anything: the one in the middle that decides what goes in. Python has a piece of syntax for exactly this pattern, called a list comprehension, and it puts the whole thing in one expression. Look at the last line on screen and read it aloud from the left: a new list, of the length of word, for each word in words. It says what you meant. The two forms do the same work; the difference is that the second cannot be got wrong in the three boring ways the first can.
