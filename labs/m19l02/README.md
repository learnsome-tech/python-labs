## Check yourself

- What are the three parts of a list comprehension, and in what order do they appear?
- What is the difference between an if before the for and an if after the source?
- How do a dictionary comprehension and a set comprehension differ on screen?
- When should you write the loop instead, and why?
- What does a generator expression give you that a list comprehension does not, and what does it cost?
