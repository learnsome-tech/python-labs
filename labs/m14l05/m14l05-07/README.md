## Goal

You can recall the whole of chapter three in one pass: comparisons, the three shapes of an if statement, nesting, the Boolean operators, tuples, while loops, the three argument range, and how any value is read as True or False.

In the lesson: A literal tuple is a comma separated collection of values inside parentheses. With a single element it must still carry a comma after that element, otherwise the parentheses are read as ordinary grouping. A tuple is a kind of sequence, and unlike a list it is immutable: once made, it cannot be altered. Two uses matter most. A function that needs to return more than one value wraps them in a tuple, and the call can then sit in a multiple assignment that pulls the parts back out, as shown. And a list may hold tuples, in which case a for loop heading can assign to several variables from each element in turn.
