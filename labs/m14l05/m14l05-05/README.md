## Goal

You can recall the whole of chapter three in one pass: comparisons, the three shapes of an if statement, nesting, the Boolean operators, tuples, while loops, the three argument range, and how any value is read as True or False.

In the lesson: Three operators combine conditions. And gives True only when both of its conditions are True. Or gives True when at least one of them is True, including when both are. Not gives True only when its condition is False. Remember that the comparison operators bind more tightly than these three, so a comparison on either side of an and needs no parentheses. Python also stops as soon as it knows the answer. If the left side of an and is False, the right side is never evaluated, and the same goes for an or whose left side is already True. That is called short circuiting.
