## Goal

You can recall the whole of chapter three in one pass: comparisons, the three shapes of an if statement, nesting, the Boolean operators, tuples, while loops, the three argument range, and how any value is read as True or False.

In the lesson: Several string methods return a Boolean, which makes them ready to drop straight into a condition. The startswith method is True when the string begins with the text you give it, and endswith is True when it finishes with it. The in operator works on strings too, testing for a substring. None of these needs comparing with True: the method has already given you the answer. The replace method is different. It returns a new string with up to a given number of occurrences swapped for something else, and the original string, like every string, is left untouched.
