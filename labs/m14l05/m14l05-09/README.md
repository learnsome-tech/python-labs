## Goal

You can recall the whole of chapter three in one pass: comparisons, the three shapes of an if statement, nesting, the Boolean operators, tuples, while loops, the three argument range, and how any value is read as True or False.

In the lesson: The general form of range takes three arguments: a start, a value to stop just before, and a step. It yields the start, then the start plus one step, and so on, each element a step further than the last, ending before it reaches the second argument. If the step is positive that second value is larger than the last element produced. If the step is negative, as on screen, the sequence counts down and the second value is smaller than the last element. That is how you write a countdown. And a while loop can express the same thing whenever the number of repetitions is not known in advance.
