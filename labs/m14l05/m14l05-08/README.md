## Goal

You can recall the whole of chapter three in one pass: comparisons, the three shapes of an if statement, nesting, the Boolean operators, tuples, while loops, the three argument range, and how any value is read as True or False.

In the lesson: A while loop does its indented block while the condition is True, testing again at the heading after each pass. It never stops in the middle of a block, even if the condition becomes False part way through. The basic pattern is initialisation, then the heading, then the main action, then whatever prepares the variables for the next time round. Interactive loops follow a variant: read the first piece of data before the loop, test it in the heading, process it, then read the next piece at the foot of the loop. The code that reads the data appears twice, and it must. Often the signal to stop is a sentinel, an agreed value that means no more data.
