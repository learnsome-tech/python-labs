## Goal

You can recall the whole of chapter three in one pass: comparisons, the three shapes of an if statement, nesting, the Boolean operators, tuples, while loops, the three argument range, and how any value is read as True or False.

In the lesson: All Python data can be converted to Boolean. Only a few things count as False: the value False itself, the special value None, any numeric value equal to zero, and any empty collection or sequence, such as the empty list and the empty string. Everything else is True. The useful consequence is on screen: name a list as the condition and you have asked whether it holds anything. The trap is that or and and hand back one of their operands rather than a Boolean, so a condition that mixes a comparison with a bare string can be True for every input and never raise an error.
