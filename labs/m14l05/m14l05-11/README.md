## Goal

You can recall the whole of chapter three in one pass: comparisons, the three shapes of an if statement, nesting, the Boolean operators, tuples, while loops, the three argument range, and how any value is read as True or False.

In the lesson: Two techniques from the graphical work are worth carrying forward. A repeating pattern is essentially circular, so there may be several places you could cut it open to make a loop body. The cut has to fall where the continuation test is ready to run, and when you move it, you change which statements must appear before and after the loop, sometimes repeating or undoing an action from inside it. The second is Zelle's checkMouse, which tests whether the mouse was clicked without stopping to wait for one, so an animation can keep moving until the user decides it has run long enough.
