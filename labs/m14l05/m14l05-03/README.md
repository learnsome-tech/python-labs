## Goal

You can recall the whole of chapter three in one pass: comparisons, the three shapes of an if statement, nesting, the Boolean operators, tuples, while loops, the three argument range, and how any value is read as True or False.

In the lesson: An if statement comes in three shapes. Plain if does the indented block when the condition is True and skips it otherwise. If else adds a second block for when the condition is False, and exactly one of the two runs. The most general form adds any number of elif lines, each with its own condition and its own block, and optionally a final else. The if, every elif, and the else all line up at the same indentation. Exactly one block runs: the one belonging to the first True condition, or the else block when every condition is False. Leave the else out and it is possible for no block to run at all.
