## Goal

You can recall the whole of chapter three in one pass: comparisons, the three shapes of an if statement, nesting, the Boolean operators, tuples, while loops, the three argument range, and how any value is read as True or False.

In the lesson: Control statements nest inside one another. An if statement inside a loop means the loop no longer has to do the same thing every time; it only has to start with the same test. Loops nest as well, and the inner loop completes all of its repetitions each time before control returns to the outer heading. What decides which statement belongs to which heading is nothing but the indentation, so line your code up carefully. Getting the indentation wrong often does produce an error message, an unexpected indent or a missing block being the commonest. When both levels are legal, though, there is no error at all, just a program that runs and quietly does the wrong thing.
