## Goal

You can recall the whole of chapter three in one pass: comparisons, the three shapes of an if statement, nesting, the Boolean operators, tuples, while loops, the three argument range, and how any value is read as True or False.

In the lesson: Comparison operators produce a Boolean result: either True or False. There are six of them, and only two need care. Equality is a double equals sign, because a single one already means assignment, and the test for not equal is an exclamation mark followed by an equals sign. Comparisons may also be chained, as on screen, which reads exactly as it does in mathematics and saves you writing and between each pair. The in operator belongs here too: a value in a sequence is True when that value is one of the elements of the sequence.
