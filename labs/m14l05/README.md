## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### One exercise using the whole chapter

1. Write guessGame.py with a function that plays one round and returns a tuple.
2. Pick a secret number with the random module, then read guesses with a while loop.
3. Continue while the guess is wrong and fewer than ten guesses have been made.
4. Return the secret and the number of guesses; unpack that tuple where you call it.

> **Hint:** The heading needs a compound condition, so both parts must be ready before the loop and refreshed at the foot of it.

## Check yourself

- Which of the three if shapes can leave every block unexecuted, and why?
- When is the condition of a while loop tested, and when is it not?
- What does range with a negative third argument produce, and where does it stop?
- Why must a one element tuple carry a comma after its only element?
- Name every kind of value that Python reads as False.
