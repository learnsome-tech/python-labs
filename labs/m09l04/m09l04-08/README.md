## Goal

You can cut a string into a list of parts with split, with or without a separator, glue a sequence of strings back together with join, and use the pair in sequence to rewrite a phrase.

In the lesson: As the dir listing showed, there are many more operations on strings than we have discussed, and there are further variations of the ones above that take more parameters. The methods startswith, endswith and replace are discussed later, when we get to conditions. If you want to reach a systematic reference from inside Idle, go to the Help menu, then Python Docs, then the Library Reference, and find the section on built-in types and the subsection for the type str. Many of the methods listed there use features we have not discussed yet, but several are already within reach: capitalize, title, strip and rfind among them. Browsing that list once is time well spent, because half of programming is knowing that the method you want already exists.
