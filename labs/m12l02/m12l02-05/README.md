In the lesson: Split and join are opposites, and both are worth memorising. Split with no parameter breaks a string at any run of whitespace, meaning blanks, tabs or newlines, and returns the remaining pieces as a list. Split with a separator string removes that separator instead, so a line of comma separated values becomes a list of values. Join goes the other way, and notice which object it belongs to: the separator, not the list. The separator string sits in front of the dot and the sequence of strings goes inside the parentheses, and out comes one string with the separator interleaved between the pieces.
