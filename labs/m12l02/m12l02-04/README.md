In the lesson: Four methods to keep. Upper and lower hand back a changed copy of the string, and note the word copy, because the original cannot be modified at all. Count says how many times a substring appears. Find gives the index of the first character of the first appearance, and it takes an optional start, or even a start and an end, so the search can be confined to a slice of the string. That optional start is exactly what made the cue finder work. Many more string methods exist, and they are listed in the Python reference manual in the section on built-in types.
