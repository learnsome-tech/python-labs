## Goal

You can name every object, method and technique chapter two introduced, and say which section to return to for any of them that you cannot yet explain.

In the lesson: Files in one screen. Open with a name alone, or with the read mode, and you get a file object for reading, where the name must refer to a file that already exists. Open with the write mode and you get a file object for writing: the file is created if it was not there, and every previous content of it is erased if it was. The read method returns the entire contents of the file as a string. The write method puts a string into the file with no extra newline. Closing a file you only read is generally unneeded, unless you want to read it again while the program is still running. Closing a file you wrote is important.
