### Chapter Two Review Exercise

1. Write words.py: read a text file of your choosing with the read method.
2. Split the contents into a list of words, and report how many words there are.
3. Build a set from that list, and report how many different words there are.
4. Write those different words in upper case, one to a line, into a second file.

> **Hint:** Every piece is somewhere in this summary: open and read, the split method, the set constructor, a for loop, upper, and a newline code you add yourself.

## Check yourself

- What is the difference between a constructor call and a method call?
- Why can you read a character of a string by index but never assign one?
- Which object does the join method belong to, and what goes in the parentheses?
- What does the set constructor do to the repetitions in a list?
- Which of the two closes matters more, the one after writing or the one after reading?
