In the lesson: A single character comes out of a string by index. If the string has length L, the indices run from zero for the first character to L minus one for the last, and negative indices count from the right, minus one being the rightmost. Strings are immutable, so you may read a character that way but you may never assign one. A slice takes a run of characters instead: a start, and the index one past the last character you want. Leave the start out and Python uses zero. Leave the end out and it uses the length. An index beyond an end is treated as that end.
