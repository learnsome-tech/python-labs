## Goal

You can name every object, method and technique chapter two introduced, and say which section to return to for any of them that you cannot yet explain.

In the lesson: Two notations carried the whole chapter. First, when the name of a type is used as a function call it is a constructor: a new object of that type is built and handed back, with no return statement anywhere in sight, and what the parameters mean depends on the type. Second, an object, then a dot, then a method name, then parentheses. Methods are functions that belong to a type and are applied automatically to the object in front of the dot, with any further parameters inside the parentheses. Every string, list, set, file and graphics shape in the chapter obeys those two patterns.
