In the lesson: Append adds one element to the end of a list. It mutates the list and returns nothing, so assigning its result to a name is a classic beginner error. A set is a collection of elements with no repetitions, and it can be used as a sequence in a for loop. The set constructor takes any other sequence and converts it, dropping the repetitions, which is how the mad lib program turned eleven cues into four. A non-empty set literal is written in braces. Remember too that a set has no order, so the order a loop over one gives you is not something to rely on.
