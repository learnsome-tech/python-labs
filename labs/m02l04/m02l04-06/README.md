## Goal

You can explain how a command name becomes a program on disk, tell python, python3 and py apart on any of the three operating systems, and ask an interpreter for its own path, version and module search path.

In the lesson: Having several Pythons is normal, not a mess. Installing a new release does not remove the old one, and that is deliberate: a project pinned to an older version keeps working. What changes is how you choose. On Windows the launcher is the chooser: list every Python with its zero option, and run a particular one by naming the version after a dash. On a Mac or on Linux, the versions have their own command names, with the version number on the end, and those always mean exactly what they say. Later, in the module on virtual environments, you will make this choice once per project and stop thinking about it.
