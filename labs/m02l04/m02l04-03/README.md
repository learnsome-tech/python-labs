## Goal

You can explain how a command name becomes a program on disk, tell python, python3 and py apart on any of the three operating systems, and ask an interpreter for its own path, version and module search path.

In the lesson: Three command names turn up in Python instructions, and which of them exists depends on your operating system. On Windows, python is the install you made, python three usually finds only the Store stub, and py is the launcher that came with the installer. On a Mac, python three is your Python, and plain python does not exist at all, because Apple removed the old version two that used to own that name. On Linux, python three is the system Python, and plain python is often missing for the same reason. So when a tutorial says python and nothing happens, try python three, and on Windows try py.
