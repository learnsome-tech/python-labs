## Goal

You can create a virtual environment for a project, activate and deactivate it on your own operating system, explain what activation does to PATH, and check from inside Python whether you are in one.

In the lesson: Creating it is not using it. On a Mac or on Linux you activate it with the source command, naming the activate script inside the bin folder. Watch the transcript. Before activation, which python three answers with the Python you installed, the one on your path for everything. Run the source line and two things change: your prompt gains the environment name in brackets, so you can see at a glance which environment you are in, and which python three now answers with the copy inside your project. Type deactivate, with no arguments, and everything goes back. Activation lasts for that one terminal window, and closing the window ends it, which is exactly what you want.
