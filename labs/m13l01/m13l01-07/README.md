## Goal

You can write a condition, say whether it is True or False, and use a simple if statement to run a block of code only when the condition holds.

In the lesson: In general a simple if statement is a heading and an indented block, exactly like the headings you already met on function definitions and for loops. The heading is the word if, then a condition, then a colon. Underneath comes a block of one or more statements, all indented by the same amount. If the condition is true, the block runs. If the condition is false, the block is skipped. In both cases, when the if statement is finished, the program continues at the next statement that is not indented under it. The indentation is not decoration; it is how Python knows where the block ends.
