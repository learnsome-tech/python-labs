# m13l01-03 · True and False wear no quotes

## Goal

You can write a condition, say whether it is True or False, and use a simple if statement to run a block of code only when the condition holds.

In the lesson: One trap catches almost everybody once. The Boolean values True and False have no quotes around them. Just as one two three inside quotes is a string while one two three without quotes is a number, the word True inside quotes is a string of four letters, and it is not of type bool at all. On screen you can see the difference laid out. The first line is the Boolean value. The second is a string that happens to spell the same word. The third is a comparison, and its value is the Boolean, not the string. Let us prove that in the shell rather than take my word for it.
