## Goal

You can write a while loop whose condition is tested before every pass, spot a loop that will never stop, and use the three argument range function to replace a counting while loop with a for loop.

In the lesson: Every loop so far has gone all the way through a specified list, and a for loop has always needed one. That is often too restrictive. A while loop behaves much like the English usage. If I say: while your tea is too hot, add a chip of ice, you would test the tea, add a little ice if it were too hot, then test again, and as long as you found it was still too hot you would go back and add more. Python's syntax is the same shape. The word while, a condition, a colon, and then an indented block. The block runs again and again for as long as the condition is true.
