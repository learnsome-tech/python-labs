## Goal

You can read the revised mad lib program function by function, explain why getKeys returns a set, and name the creative problem solving steps that produced it.

In the lesson: Before we leave this section, an exercise in exactly the same shape as getKeys. A function is to print the index of every place where a target substring appears in a string. On screen are two calls and what they should print. Searching the phrase for the word is finds it at index two, at index five, and again at index eleven inside the word dish. Searching for the letter h finds index one and index thirteen. The example file you start from already counts the appearances and sets up the repeat loop for you. What you add is the index work: the initialisation before the loop and the general form of find, the one that takes a starting position, so each search carries on where the last one stopped.
