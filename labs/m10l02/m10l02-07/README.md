## Goal

You can read the revised mad lib program function by function, explain why getKeys returns a set, and name the creative problem solving steps that produced it.

In the lesson: The main function holds the original story as a triple quoted string, hands it to the story teller, and then waits for one more press so the window does not vanish. The last line of the file calls main, which starts everything. Run the program and you are asked for an animal, a food and a city, once each, with no repeats. Here I answered elephant, mangoes and Paris, and out came the finished story with every cue filled in. Your prompts may well arrive in a different order than mine, because the cues came from a set, and a set has no order. That is why this transcript is shown rather than checked line by line.
