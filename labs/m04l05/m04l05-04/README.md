## Goal

You can tell a literal from an identifier, say which character sequences Python allows as a name, avoid the reserved words, and name multi word variables in a conventional way.

In the lesson: For the curious, you may read the full list, and here it is. There are thirty five reserved words. You do not need to memorise them, because you will meet almost all of them during this course, and Idle colours them orange the moment you type one, which is warning enough in practice. Three of them, False, None and True, begin with a capital letter, because they are values rather than instructions. There are also identifiers that are automatically defined in Python, and that you could redefine, but you probably should not unless you really know what you are doing. When you start the editor, we will see how Idle uses colour to help you know which identifiers are predefined.
