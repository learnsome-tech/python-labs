## Goal

You can package related values in a tuple, unpack a tuple in a for loop heading, and replace a long repetitive if elif statement with a loop over a list of tuples.

In the lesson: Now what does the new function mean for the interactive part of the program? Each long if elif statement collapses to a single call, so the whole interactive section reduces to this draft. In the original only two shapes could be coloured, otherwise you would have been reading code forever. Look at the similarity between the two blocks and you can imagine another loop, one that would let many more parts be coloured. Two differences must go first: the message is created the first time and only its text set the second, and the shape and its description both change.
