## Goal

You can package related values in a tuple, unpack a tuple in a for loop heading, and replace a long repetitive if elif statement with a loop over a list of tuples.

In the lesson: This section rebuilds the choose button program from the last section around a new kind of object, the tuple. A tuple is very like a list, with two differences. A literal tuple is written inside parentheses rather than square brackets, and a tuple is immutable, meaning you cannot change it once it is made: not its length, and not any element. On screen are two of them, a tuple of three numbers and a tuple of two strings. Making a tuple turns several separate items into one single object, which is exactly what this program needs.
