## Goal

You can package related values in a tuple, unpack a tuple in a for loop heading, and replace a long repetitive if elif statement with a loop over a list of tuples.

In the lesson: When a sequence of things is treated in the same way, that suggests a list and a loop. The awkward part here is that the changing data is paired: each rectangle goes with a colour string. There are several ways to handle such associations, and a very neat way in Python is a tuple, which turns the rectangle and the colour into one object. Objects like that can then go in a larger list, as on screen: one list holding three tuples, each a rectangle with the colour it stands for.
