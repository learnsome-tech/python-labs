## Goal

You can package related values in a tuple, unpack a tuple in a for loop heading, and replace a long repetitive if elif statement with a loop over a list of tuples.

In the lesson: The first difference is easy to remove. Create the message once with an empty piece of text, draw it, then set its text in a separate statement, so both blocks have the same shape. What remains changing is the shape object and its description: tuples of shape and description, held in a list, can drive a loop. On screen the list is written out with the roof added, so three shapes can be coloured instead of two, and the prompt is built by joining the description into a sentence. Can you finish the body of the loop yourself? Look back at the original interactive code first.
