## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### Choose Button Exercise

1. Save chooseButton2.py as chooseButton3.py and extend buttonSetup with one more colour.
2. Add a further shape to the picture and extend shapePairs so it can be coloured too.
3. Optional: also prompt for an outline colour for each shape, and carry out the change.
4. Optional challenge: write makeButtonSetup, building buttonSetup from a list of colour names.

> **Hint:** In the challenge, the x coordinate never changes and the y coordinate falls by a fixed step.

## Check yourself

- Name the two ways a tuple differs from a list.
- What does the for heading do with each tuple it takes from the list?
- Why can a for loop replace an if elif chain only when a return is available?
- Why are the individual names of the buttons no longer needed?
- In the append call, what does each of the two pairs of parentheses do?
