## Goal

You can put an Entry box in a graphics window with its own label, use a mouse click as the signal that typing has finished, and read or set its contents with getText and setText, converting to numbers where you need them.

In the lesson: In main, all that setting up collapses into two calls. Notice that extra parameters were added even though only one value is used for each: the author expected to want labelled entries again later. These lines also show something you have seen in the Shell, that a statement may run over more than one line. Python can tell there must be a continuation, because the brackets do not yet match. Then the conversions were tidied too. The string variables existed to make a teaching point, but each was used only once, so the read and the conversion are folded into a single line each.
