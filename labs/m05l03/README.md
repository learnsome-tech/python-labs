## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### Addition Format Exercise

1. Write add3f.py, a version of your earlier add3.py.
2. Use the string format method to construct the same final string as before.
3. Ask for three numbers; report all three and their sum.

> **Hint:** One format string with four pairs of braces, and four parameters in the matching order.

### Quotient Format Exercise

1. Write quotientformat.py, a version of the quotient problem.
2. Use the string format method to construct the same final string as before.
3. Give a full sentence: both initial numbers, the quotient and the remainder.

> **Hint:** Four values go into the sentence; you may number the fields if that makes the order easier to see.

## Check yourself

- In the expression that greets a person, what is the object, what is the method, and what is the parameter?
- Where do the values for empty pairs of braces come from, and in what order?
- When do you have to number the replacement fields?
- How do you make a literal brace appear in the formatted string?
- What does the format method do for you that joining with plus signs does not?
