## Goal

You can build a string with the format method, substituting values into replacement fields by position, repeating a field, and showing a literal brace.

In the lesson: In grade school quizzes a common convention is to fill in the blanks: you are given a line of text with a gap, and you write the name of the person greeted into the gap. Python has a similar construction, better called fill in the braces. There is a particular operation on strings called format, which makes substitutions into places enclosed in braces. The string carries the fixed text and marks the holes; the format parameters supply what goes into them. Learn this properly, because you will use it for output for the rest of the course, and again when you build web pages.
