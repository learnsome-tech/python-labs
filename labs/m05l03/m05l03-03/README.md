## Goal

You can build a string with the format method, substituting values into replacement fields by position, repeating a field, and showing a literal brace.

In the lesson: There are several new ideas in that one line, and the biggest is the punctuation. This is method calling syntax for objects, which you will meet in detail at the beginning of the next chapter. All data in Python are objects, including strings. Objects have a special syntax for functions belonging to their particular type of object, and such a function is called a method. The syntax has the object, a period, the method name, and any further parameters in parentheses. Here the object is the string with the braces in it, the method is named format, and there is one further parameter, person.
