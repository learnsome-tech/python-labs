## Goal

You can build a string with the format method, substituting values into replacement fields by position, repeating a field, and showing a literal brace.

In the lesson: An optional elaboration, which earns its keep in a moment. Imagine the format parameters numbered in order, starting from zero: here zero, one and two. The number of the parameter position may be included inside the braces. That gives an alternative to the last line of interview two dot py, added as the last line of the example file interview three dot py, shown here. On its own this is more verbose than the version with empty braces, with no obvious advantage. Everything else in that file is as you have already seen. The advantage appears when you want a parameter more than once.
