## Goal

You can build a string with the format method, substituting values into replacement fields by position, repeating a field, and showing a literal brace.

In the lesson: One preview, because you will see it in other people's code. Python later gained a simplification for formatting, called an f-string: you write the letter f directly before the opening quote of the literal, and put the names themselves inside the braces, instead of listing parameters after a call to format. The values of those local variables are substituted automatically. We meet it properly alongside dictionaries and string formatting in a later module, where there is a full example to run. Until then, the format method is what this tutorial uses.
