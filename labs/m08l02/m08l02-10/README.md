## Goal

You can raise numbers to powers, take square roots with a fractional exponent or with the math module, and round a float for display with the format function or a format string, without changing the value itself.

In the lesson: Keep two ideas apart. Formatting a number gives you a string for a human to read and leaves the value alone, so the next calculation still uses every digit. The round function is different: it gives back a number, an actual float, rounded to the places you ask for. Use formatting when you are about to print, and full precision everywhere else, so errors have no chance to accumulate. And carry the tutorial's warning with you: do not depend on the exactness of floating point arithmetic, even for apparently simple expressions.
