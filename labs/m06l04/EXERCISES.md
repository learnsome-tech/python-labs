## Exercise 1: Quotient Function Exercise

1. Modify quotientformat.py from the earlier quotient format problem, saving it as quotientProb.py.
2. Create a function quotientProblem with numerical parameters.
3. It should print a full sentence with the inputs, the quotient and the remainder.
4. Have main test it on several sets of literal values, and also with input from the user.

> **Hint**: Addition five is your model: arithmetic and printing in the function, keyboard work in main.
