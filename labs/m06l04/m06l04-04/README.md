## Goal

You can define and call a function with several parameters, and explain how the arguments are matched to the parameter names from left to right.

In the lesson: After addition five has run in Idle, the Shell remembers sumProblem, so you can call it again yourself with whatever values you like. Here is the pair from the program, then a different pair, and then the same pair the other way round. Look carefully at the last two lines of output. The sum is the same, because addition does not care about order, but the sentence is not: whichever number you write first becomes the value of x, and x is printed first. That is the visible proof that position, and only position, decides which value lands in which formal parameter.
