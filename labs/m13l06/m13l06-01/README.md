## Goal

You can test what a string starts with, ends with or is made of, and build up conditions from string methods such as startswith, endswith, replace and isdigit.

In the lesson: Conditions do not have to be comparisons. Any expression whose value is a Boolean will do, and strings come with methods that hand you one directly. Here are the ones this section adds, all written as a method on a string called s. The first two ask what the string begins or ends with. The third asks whether every character is a digit. The fourth is different: it does not answer a question but builds a new string with some occurrences swapped for something else. Remember that strings are immutable, so replace never alters the string you call it on; it returns a fresh one, and you have to keep it.
