## Goal

You can recite the order of work for building a dynamic web page, and say what each piece of markup, each cgi module call and each error location is for.

In the lesson: Plain text may be marked up to include formatting. That formatting may be readable only by a computer, or it may be readable by humans, and one human readable form is hypertext markup language. Its markup involves tags enclosed in angle brackets, and an ending tag starts with a slash, as in the title example on screen. Tags may be modified by attributes, specified much like Python string assignments, as in the input field below it. Modern editors let HTML be edited almost like a word processor, and two views of the data are useful: the formatted view, and the source view showing the raw markup.
