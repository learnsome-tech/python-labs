## Goal

You can recite the order of work for building a dynamic web page, and say what each piece of markup, each cgi module call and each error location is for.

In the lesson: Python and HTML get along easily, and the reason is worth restating: since HTML is just a text string, it can be manipulated in Python and read from and written to text files. Everything you learned about strings, files and the format method applies without change. The one genuinely new tool in the chapter is on screen. The webbrowser module has a function called open, which will open a file, or a web address, in your default browser. That is what turned a string your program built into a page in front of you, in the programs that ran locally without a server.
