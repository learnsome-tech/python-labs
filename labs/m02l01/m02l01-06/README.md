## Goal

You can install Python on Windows from python.org with the PATH box ticked, verify it in a fresh command prompt with both py and python, and recognise and fix the Microsoft Store stub message.

In the lesson: It is worth knowing where the files went, because you will want those folders again. A single user install goes under your own AppData folder, in the path on screen, ending in a folder named for the version. Inside it is python dot exe. Beside that is a folder called Scripts, where pip and any command line tools you install later appear. Both of those folders are what the PATH checkbox added. The launcher is different: it goes into the Windows folder itself, which is always searched, and that is why py often answers when python does not.
