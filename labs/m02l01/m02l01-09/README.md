## Goal

You can install Python on Windows from python.org with the PATH box ticked, verify it in a fresh command prompt with both py and python, and recognise and fix the Microsoft Store stub message.

In the lesson: The last check is to go inside. Type py on its own and press Enter. You get the banner: the version first, then a stamp in brackets naming the build and the compiler, which changes from one release to the next, and then the platform name. Do not be alarmed that the platform name ends in thirty two; every Python on Windows reports that, and the sixty four bit note in the same brackets tells you the right build is running. Under the banner is the triple angle bracket prompt. Type a sum, press Enter, and it answers. To leave, call the exit function, or hold control and press Z, then Enter.
