# m02l01-03 · The checkbox that decides everything

## Goal

You can install Python on Windows from python.org with the PATH box ticked, verify it in a fresh command prompt with both py and python, and recognise and fix the Microsoft Store stub message.

In the lesson: Double click the file you downloaded and the installer opens one small window. Nearly everything on it can be left alone, but along the bottom are two checkboxes, and one of them decides whether the rest of this module works for you. Tick the box that adds python dot exe to PATH. PATH is the list of folders your command prompt searches when you type a command, and ticking that box puts the new Python folder on the list. Leave it unticked and typing python finds nothing at all, even though Python is installed perfectly well. Tick the other box too, the one offering admin privileges for the launcher.
