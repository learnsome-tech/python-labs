## Goal

You can install Python on Windows from python.org with the PATH box ticked, verify it in a fresh command prompt with both py and python, and recognise and fix the Microsoft Store stub message.

In the lesson: Windows has never come with Python installed, so the first job is to fetch it, and where you fetch it from decides how closely the rest of this course matches your screen. The address on screen is the downloads page at python dot org, run by the Python Software Foundation, the people who make the language. Windows also offers Python through the Microsoft Store. That build is published by the same foundation and it does work, but it installs into a sandboxed folder, it leaves out the py launcher, and it updates on Microsoft's schedule rather than yours. We will use the python dot org installer, so every folder and every command I mention is the one in front of you.
