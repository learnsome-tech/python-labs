# m02l01-08 · Verifying in a fresh command prompt

## Goal

You can install Python on Windows from python.org with the PATH box ticked, verify it in a fresh command prompt with both py and python, and recognise and fix the Microsoft Store stub message.

In the lesson: Now prove it. Close any command prompt you already had open, because a terminal reads PATH when it starts and yours is holding an old copy. Open a new one from the Start menu and type the four commands on screen. Here are the four answers you want. The launcher reports a version. Plain python reports the same version. The where command prints the full path of whatever answers to the name python, which should be the one under AppData. And the launcher's list option prints every Python installed, with a star beside the one it would choose.
