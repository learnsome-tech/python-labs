# m02l01-07 · SmartScreen, and the permission prompt

## Goal

You can install Python on Windows from python.org with the PATH box ticked, verify it in a fresh command prompt with both py and python, and recognise and fix the Microsoft Store stub message.

In the lesson: Two warnings may appear while you install, and neither means anything is wrong. The first is a blue box saying Windows protected your PC. That is SmartScreen, and it appears because the file is new to it, not because the file is bad. Click More info, check that the publisher named is the Python Software Foundation, then click Run anyway. Do that only for a file you downloaded from python dot org yourself. The second is the permission prompt asking to allow changes to your device. If the publisher shown there is unknown, cancel, delete the file, and download it again.
