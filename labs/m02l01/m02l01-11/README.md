## Goal

You can install Python on Windows from python.org with the PATH box ticked, verify it in a fresh command prompt with both py and python, and recognise and fix the Microsoft Store stub message.

In the lesson: There are three ways out, and any of them will do. The tidiest is to run the installer again, choose Modify, click through to the advanced options, and tick the box that adds Python to your environment variables. The second is to switch the stub off: open Settings, find app execution aliases, and turn off the entries for python and for python three. The third is to add the folder to PATH by hand, putting it above the WindowsApps folder. Whichever you choose, open a brand new terminal afterwards, because the one you were using still holds the old list.
