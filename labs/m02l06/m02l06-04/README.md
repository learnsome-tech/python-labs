## Goal

You can set up a blank-free Python folder, unzip the tutorial's Python 3 examples into it, and run madlib.py on Windows, Mac or Linux.

In the lesson: This section assumes Python three is already on your computer. Windows does not come with Python, and the appendix on obtaining Python covers that. Find the file madlib dot py in the Python folder you just set up. On Windows, display your folder contents and double click on it to start the program. On a Mac, Control-click the file in the Finder, select Open With, and choose the Python Launcher for your Python three version; when you are done, close the terminal window. On Linux, open a terminal window, change into your Python examples directory, and enter the first command on screen. If you need to distinguish version two from version three, use the second one instead. If neither works, get help, or open the program in Idle, which is coming up shortly. One small note: keyboards label the key that ends a line differently, Enter or Return. They mean the same key.
