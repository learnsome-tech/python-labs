## Goal

You can set up a blank-free Python folder, unzip the tutorial's Python 3 examples into it, and run madlib.py on Windows, Mac or Linux.

In the lesson: Next, the examples. Download and save the examples zip archive from the tutorial's own site; the address is on screen. Note that the examples, like this version of the tutorial, are for Python three. There were major changes to Python in version three point zero, making it incompatible with earlier versions. If you are using Python two point seven for some good reason, do not use these files. Go to the hands-on Python home page instead and follow the links to the matching older tutorial and its examples. Two optional downloads sit on the same page. One is an archive of the web version of the tutorial, for reading without an internet connection. The other is a PDF of the whole tutorial for printing. Unzip the web one exactly as you are about to unzip the examples, then open the index page inside the unzipped folder in your browser.
