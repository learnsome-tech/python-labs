## Goal

You can set up a blank-free Python folder, unzip the tutorial's Python 3 examples into it, and run madlib.py on Windows, Mac or Linux.

In the lesson: Here is the top of the file that you just ran. Do not try to read it as code yet. What matters now is the shape of it. There is a note saying what the file does and who it came from, and then the whole story is kept as one long piece of text. The words inside braces, animal, food and city, are holes waiting to be filled. The rest of the file, which is off screen for the moment, says what happens when the program runs, and the next module walks through every line of it. Let us run it. The program asks you three times for a word, one prompt at a time, then prints the story with your words dropped into every matching hole. Try the program a second time and make different responses. The same template, a completely different tale.
