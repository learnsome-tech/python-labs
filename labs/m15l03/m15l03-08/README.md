## Goal

You can start the local Python web server, read the small CGI scripts the tutorial builds up, and say which of the three places an error will show itself in.

In the lesson: Fill out the adder form once more, and look at the address in your browser when the result appears. You see the script name, a question mark, then the names x and y with the values you entered. That is one mechanism for delivering form data to the script. In fact no form is needed for that association: go directly to the addresses on screen, with values typed by hand, and you get the arithmetic with no form at all. It makes testing far easier.
