## Goal

You can start the local Python web server, read the small CGI scripts the tutorial builds up, and say which of the three places an error will show itself in.

In the lesson: For a complete example, with the server going, open the adder page through localhost. You see a web form. Enter two integers, click the Find Sum button, and back comes a page built from the numbers you typed. Look at the server console: there is a log of the activity. Now close that window and try the same link again. You get an error, because you referred to localhost and you just stopped the server. Restart it: we want it for the rest of the chapter.
