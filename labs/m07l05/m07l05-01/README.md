# m07l05-01 · Adding up a list: begin with the heading

## Goal

You can build a loop that accumulates a result, choose the right initial value for the accumulator, and recognise from an English description when a loop through a sequence is needed.

In the lesson: Suppose you want to add up all the numbers in a list called nums. Let us plan this as a function right from the start, so we begin with a heading and a documentation string that promises to return the sum. Now, what goes in the body? If you cannot see what to do straight away, here is a technique that almost always helps. Write down one concrete case and think through how you would solve that case in complete detail, by hand. Take the list of four numbers on the screen. How would you actually add those up? Do it in your head now, and notice what you do.
