## Goal

You can choose between a list, a tuple, a set and a dictionary for a given job, say what each costs to search, and explain why a tuple can be a dictionary key when a list cannot.

In the lesson: You have met all four of these already, one at a time. Putting them side by side is what makes choosing easy, and the whole table comes down to four questions. Does order matter? Will the collection change after you build it? Are duplicates meaningful? And will you keep asking whether something is in it? Answer those four and the container picks itself. Notice that a list and a tuple differ in exactly one column, change, and that a set and a dictionary are the two fast ones for asking whether something is present. Everything else in this lesson is showing you each row is true, and then some concrete decisions.
