## Goal

You can open a graphics window, construct points, circles, lines and rectangles, colour them, draw them, move them and close the window, and you know why the vertical axis points the wrong way.

In the lesson: The tutorial ships a stepped version of this introduction, so you can watch the picture grow one instruction at a time. Load it into Idle and run it, or start it from your folder window. The pattern repeats all the way down the file: a line or two of real graphics code, then a call to the input function that echoes those lines back and waits. Each time you press return the next piece runs, and you look across at the graphics window to see what changed. Run it yourself while you watch. Reading about a window appearing is never as convincing as seeing one appear.

   - Lines 6–9: press return
