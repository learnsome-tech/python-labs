## Goal

You can open a graphics window, construct points, circles, lines and rectangles, colour them, draw them, move them and close the window, and you know why the vertical axis points the wrong way.

In the lesson: So far everything has been drawn in the default colour, black. Graphics objects have methods to change that, and basic colour name strings are recognised. There are two separate colours for any shape with an inside: the boundary and the interior. The set outline method changes the boundary. The set fill method paints the interior. Run these two lines and the circle gains a red rim and a blue middle. Note the method names, because they are not specific to circles: the same two work on rectangles, ovals, polygons and lines. Fancier colours come later in this chapter.
