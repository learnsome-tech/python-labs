## Goal

You can open a graphics window, construct points, circles, lines and rectangles, colour them, draw them, move them and close the window, and you know why the vertical axis points the wrong way.

In the lesson: Now a circle. The circle constructor takes a centre point and a radius, so this one is centred on the point we already made, with a radius of twenty five pixels. As with every graphics object, creating it is not the same as showing it. It stays invisible until you explicitly use its draw method. Run these two lines and a black circle outline appears, centred on that lonely pixel. The pattern is now fixed: construct the object, then draw it into a window. From here on the tutorial writes the draw call immediately after each object, so there is always something to look at.
