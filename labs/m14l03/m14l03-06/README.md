## Goal

You can drive an interactive graphics program with a while loop, decide where to cut a repeating pattern into a loop body, and use checkMouse so an animation continues until the user clicks.

In the lesson: Other than standard graphics setup, this is what the main program contains. It makes a rectangle, calls polyHere inside it, and fills the polygon that comes back with green. Then a second, taller rectangle, another call, and an orange outline. The colour changes are an illustration. The real point is that a function which builds something interactively can hand the result back like any other value.
