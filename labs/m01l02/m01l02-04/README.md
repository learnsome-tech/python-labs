## Goal

You can explain what a high level language is, what the Python interpreter does with your instructions, and why Python is the language you are learning first.

In the lesson: No computer understands the high level instruction directly. It is not in machine language. A special program must first translate an instruction like that one into machine language. Our single high level line might be translated into a sequence of three machine language instructions, matching the three step description we just walked through. On screen you can see what that looks like: three rows of ones and zeros, one row for each step. Looking at that, you can see why high level languages were a great advance in clarity. If you go on to a broad introduction to computing, you will learn more about the layers that connect low level digital circuits to high level languages.
