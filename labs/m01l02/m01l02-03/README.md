## Goal

You can explain what a high level language is, what the Python interpreter does with your instructions, and why Python is the language you are learning first.

In the lesson: Here is an instruction that appears in many high level languages. It says z equals x plus y. To a human that is one thought. To the machine it is three separate jobs. First, access the value stored at a location labeled x. Second, calculate the sum of that value and the value stored at a location labeled y. Third, store the result in a location labeled z. Notice that the high level line hides the ordering and the storage details. That hiding is exactly why higher level languages were such an advance in clarity.
