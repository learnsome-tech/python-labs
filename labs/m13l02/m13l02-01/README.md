## Goal

You can choose between two blocks of code with an if else statement, write any of the six comparisons correctly, and test membership in a sequence with in and not in.

In the lesson: A simple if statement chooses between doing something and doing nothing. Far more often you want a choice between two different actions, and that is what else gives you. After the if heading and its indented block comes a line that reads else and a colon, at the same indentation as the if, and then a second indented block. If the condition is true the first block runs. If it is false the second block runs. Exactly one of the two happens: never both, and never neither.
