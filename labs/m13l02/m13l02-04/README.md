## Goal

You can choose between two blocks of code with an if else statement, write any of the six comparisons correctly, and test membership in a sequence with in and not in.

In the lesson: All the usual arithmetic comparisons are available, but several do not use the mathematical symbol, because those keys are not on a standard keyboard. Less than or equal is written as the less than sign followed by an equals sign, with no space between them, and greater than or equal follows the same pattern. Now the important one. The obvious choice for equals, a single equals sign, is already taken: it means assignment. So a test for equality needs an annoying second equals sign. Writing one equals sign where you meant two is among the commonest mistakes there is.
