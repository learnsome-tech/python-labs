# Exercises — If Else, And Conditional Expressions

Lesson `m13l02` · [Watch](https://learnsome.tech/courses/python-course/watch?lesson=m13l02)

## Exercise 1: Graduate Exercise

1. Write a program graduate.py that prompts a student for how many credits they have.
2. Print whether or not they have enough credits for graduation.
3. At Loyola University Chicago 120 credits are needed to graduate.


## Exercise 2: Head or Tails Exercise

1. Write headstails.py with a function flip() simulating a single flip of a coin.
2. Choose 0 or 1 with random.randrange(2); use an if-else to print Heads or Tails.
3. Print Heads when the result is 0, and Tails otherwise.
4. In your main program, use a repeat loop that calls flip() ten times.

> **Hint**: Import the random module at the top, as the graphics examples did.


## Exercise 3: Strange Function Exercise

1. Save the example jumpFuncStub.py as jumpFunc.py and complete jump and main.
2. jump(n): if n is even return n//2, otherwise return 3*n + 1. Use an if-else.
3. main(): print jump(n) for n in 0, 1, ... , 10, using a for loop over range.

> **Hint**: If you divide an even number by two, what is the remainder? Use that in your condition.
