## Goal

You can choose between two blocks of code with an if else statement, write any of the six comparisons correctly, and test membership in a sequence with in and not in.

In the lesson: There is usually more than one way to solve the same problem. This alternative body, from the example program wages one dot py, uses a single general formula and lets the if else statement set the numbers that go into it. When the hours are at most forty, the regular hours are all of them, and it sets the overtime hours to zero. Otherwise the regular hours are forty and the rest are overtime. One return statement then serves both cases, so the formula lives in only one place.
