## Goal

You can grow a list with append inside a loop, explain why that differs from concatenation, build a set to remove duplicates, and recognise a type name used as a constructor.

In the lesson: We have now seen several examples of the name of a type being used as a function. Read these earlier examples. The first converts a string of digits into the integer it stands for. The second goes the other way, turning a number into its printable form. The third builds a new empty list. The fourth converts a list of numbers into a set, dropping any repeats. In all such cases a new object of the specified type is constructed and returned, and functions that do that are called constructors. So the conversion functions from chapter one were constructors all along.
