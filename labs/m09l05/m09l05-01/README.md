## Goal

You can grow a list with append inside a loop, explain why that differs from concatenation, build a set to remove duplicates, and recognise a type name used as a constructor.

In the lesson: Before we rebuild the mad lib program so that it takes new stories easily, we need a couple of facts about other types of object built into Python. So far we have used lists, but we have never changed the contents of one. The most obvious way to change a list is to add a new element onto the end, and lists have a method for exactly that, called append. The important part is that append modifies the original list. Another word for modifiable is mutable, so lists are mutable. Most of the types we have met, including int, str and float, are immutable, which is why every string method handed back a new string instead.
