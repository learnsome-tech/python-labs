## Goal

You can grow a list with append inside a loop, explain why that differs from concatenation, build a set to remove duplicates, and recognise a type name used as a constructor.

In the lesson: If the result did not make sense, follow the details of playing computer. The tutorial numbers the six interesting lines and then walks a row down the table for each line executed. The definition happens first and does nothing else. The call sets the formal parameters, then the empty list appears, and after that rows three and four alternate, once per element: take the next number, append its product. Watch the newList column. It grows on every visit to line four, and no assignment to newList happens again after the empty list was made. A for loop with append is a powerful way to derive a new list, though not the only way.
