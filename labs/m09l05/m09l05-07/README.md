## Goal

You can grow a list with append inside a loop, explain why that differs from concatenation, build a set to remove duplicates, and recognise a type name used as a constructor.

In the lesson: A list may contain duplicates, which is sometimes useful and sometimes not. You may have learned in mathematics that a set is a collection that does not allow repetitions; a set automatically removes any repetition suggested to it. Python has a type called set. Like many type names it can be used to convert other types, and here it makes sense to convert any collection, with duplicates dropped in the process. The screen shows the tutorial's shell session: eight strings go in, five come out. Set literals are written in braces rather than square brackets. Technically a set is unordered, so your Idle may list the same set in a different order, and that is not a mistake.
