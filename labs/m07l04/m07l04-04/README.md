# m07l04-04 · A name that says: I will never use this

## Goal

You can write a simple repeat loop whose loop variable you never use, and build a loop that modifies a variable of your own on every pass, tracing its value pass by pass.

In the lesson: When you read code you look at each variable name where it is introduced, and then hunt for the places it is used later. In both repeat loops the name i is introduced because the heading needs a name in that position, and it is never used again. There is a convention for saying that out loud: name the loop variable underscore, just a single underscore character, as on the screen. Python treats underscore as an ordinary variable name, so nothing about the behaviour changes. What changes is that a human reader knows at a glance that this value is deliberately being thrown away.
