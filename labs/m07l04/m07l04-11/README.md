## Goal

You can write a simple repeat loop whose loop variable you never use, and build a loop that modifies a variable of your own on every pass, tracing its value pass by pass.

In the lesson: Step back from the colours and you have an outline you will use for the rest of your programming life. Variables that are going to be modified need initial values before the loop. The loop heading causes the repetition, and in a for loop the number of passes is the size of the sequence. The body does the thing you want done repeatedly. Then, still inside the body, there is code whose only job is to get the variables ready for the next time round. That extra preparation step is what makes this a successive modification loop.
