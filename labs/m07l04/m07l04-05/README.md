## Goal

You can write a simple repeat loop whose loop variable you never use, and build a loop that modifies a variable of your own on every pass, tracing its value pass by pass.

In the lesson: Now for the second pattern. Suppose I have a list called items holding the four colour names, and I want to print each one with a number in front of it, counting up from one. The output I would like is on the screen. Each line has a consistent shape: a number, then the item. But the numbers are nowhere in the list, so the program must produce them itself. Something must differ on each pass, and the only thing that can change is a variable. So let us introduce a variable called number.
