## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### Predict, remembering the last section on types

1. Predict the value of seven plus two, with both numbers typed as plain integers.
2. Then predict the digit seven in quotes plus the digit two in quotes.
3. Then predict the digit seven in quotes plus the plain integer two.
4. Write all three down before you check them at the shell.

### String Exercise

1. Figure out a compact way to get Python to make the string with Yes repeated five times.
2. Compact means without typing the word Yes five times over. Try it in the shell.
3. Then make the string with Maybe three times followed by Yes five times.

> **Hint:** For the second one, use two asterisks and a plus.
