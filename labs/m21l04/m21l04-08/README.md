## Goal

You can name the standard library modules a beginner actually meets, say what each one is for, recognise when a problem belongs to one of them, and look the details up for yourself.

In the lesson: So how do you find these things when you need them? Three habits. The library reference on the Python website lists every module by subject, and reading one page a week is a genuinely good use of your time. In the shell, the help function prints the documentation of anything you pass it, including a whole module, and dir lists every name a module contains, which is how you remind yourself what is in there. And when searching the web, include the word Python and the module name and prefer the official documentation to the first forum answer. The skill you are building is not memory; it is the instinct that says somebody has probably solved this already.
