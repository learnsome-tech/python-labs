## Goal

You can install Python correctly on your own platform, open and save files ending in dot cgi from Idle, and get the local server and the graphics windows behaving on Windows or on a Mac.

In the lesson: The Mac terminal, also optional. There is a current directory, and the prompt usually shows it, often ending in a dollar sign. The pwd command prints the full name of that directory, and the ls command lists what is in it. A tilde is shorthand for your home directory. The cd command changes directory, and two dots mean the parent. Here is a neat trick: type cd and a space, stop, then drag a folder from the Finder onto the terminal, and the full path appears.
