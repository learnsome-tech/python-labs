## Goal

You can install Python correctly on your own platform, open and save files ending in dot cgi from Idle, and get the local server and the graphics windows behaving on Windows or on a Mac.

In the lesson: This part is optional. Everything above is enough for the tutorial, but terminals do things no file window can. Windows has the idea of a current directory, and the prompt usually ends by showing which one you are in. Commands run when you press enter. The dir command gives a directory listing, which I have cut down to almost nothing on screen. The cd command changes directory. The two dots in the third line mean the parent directory. And you can start a program by naming the interpreter and then the file.
