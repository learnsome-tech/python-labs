## Goal

You can use the many built-in colour names, build a colour of your own from red, green and blue intensities with color_rgb, and choose random values from a range with the random module's randrange function.

In the lesson: You can also create colours of your own, and doing that takes a little knowledge of the eye. The only colours human eyes detect directly are red, green and blue, each registered by a different kind of cone cell in the retina. As far as the eye is concerned, every other colour is a combination of those three. Colour video screens use exactly this fact: they display only those three colours. The common scale for the intensity of each one runs from zero, meaning none of that colour, to two hundred fifty five, the most intense. So a colour can be described by three intensities, often abbreviated to r g b, and the graphics package gives you the color rgb function to build one.
