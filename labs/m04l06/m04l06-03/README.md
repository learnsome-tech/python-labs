## Goal

You can display anything you like with the print function, write a string literal that spans several lines, and read the escape codes that stand for a newline, a quote or a backslash.

In the lesson: Three behaviours are worth naming, because each of them is a default you can change later. First, print converts each argument to its string representation, so you can hand it numbers, strings and expressions of any type in a single call. Second, it separates the results with a single blank, which is why the sentence read properly without your typing any spaces inside the quoted pieces. Third, when it has finished it advances to the next line. Keep the second and third apart in your mind. One puts a space between the arguments, the other ends the line, and each has its own keyword for overriding it, which we will meet when we come to loops.
