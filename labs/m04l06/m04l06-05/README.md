## Goal

You can display anything you like with the print function, write a string literal that spans several lines, and read the escape codes that stand for a newline, a quote or a backslash.

In the lesson: That strange answer indicates an alternate way to encode the string internally in Python, using escape codes. Escape codes are embedded inside string literals and start with a backslash character. They are used to embed characters that are either unprintable, or have a special syntactic meaning to Python that you want to suppress. Here is the short list of the most common ones. Backslash backslash stands for one backslash. Backslash n is the newline character. Backslash single quote and backslash double quote give you those quote characters even inside a string delimited by the same kind of quote. The newline character indicates that further text will appear on a new line when printed. When you use the print function, you get the actual printed meaning of the escape coded character.
