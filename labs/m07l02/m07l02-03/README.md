## Goal

You can build strings with the format method and a dictionary unpacked by two stars, and use locals or an f-string to drop local variable values straight into a format string.

In the lesson: Now we go one step further. The keyword parameters associate the keyword names with the values after the equal signs. The dictionary from spanish two a includes exactly the same associations: one with uno, two with dos, three with tres. There is a special notation allowing such a dictionary to supply keyword parameters. Assuming dictionary is the Spanish dictionary, the first method call on screen returns the same string as the second. The two stars before the dictionary indicate that it is not to be treated as a single actual parameter. Instead, keyword arguments for all the entries in the dictionary effectively appear in its place.
