# Exercises — Classes And Instances

Lesson `m20l01` · [Watch](https://learnsome.tech/courses/python-course/watch?lesson=m20l01)

## Exercise 1: Make a class of your own

1. Write a class Rectangle whose initialiser takes a width and a height and stores both.
2. Make two rectangles of different sizes and print all four numbers.
3. Set a new attribute called colour on one of them, then print vars of both.

> **Hint**: vars on an instance shows the attributes that instance is actually carrying.
