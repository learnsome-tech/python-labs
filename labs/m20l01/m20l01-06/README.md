## Goal

You can write a class with an initialiser, create instances of it, store data on each instance, and explain the difference between the class and an instance of it.

In the lesson: Say it once more, in plain words, because it is the single idea that makes the rest of this module easy. There is exactly one Dog class in your program. There is a fresh instance every time you call it. The class says what a dog is: it has a name, it has an age. An instance is one particular dog with one particular name. Data about a specific dog is set on self inside the initialiser, so it lives on the instance, and asking the class for it fails. If you ever find yourself wanting to keep one dog's details on the class, that is a sign the design has slipped, and the next lesson gives you the vocabulary to say why.
