## Goal

You can write a class with an initialiser, create instances of it, store data on each instance, and explain the difference between the class and an instance of it.

In the lesson: You have been using classes since your very first string. When you call the upper method on a string, that method is not kept inside your particular string; it belongs to the type of all strings, which Python calls str. A class is exactly that: a description of a type, saying what data a value of that type carries and what operations it offers. Every string you have made is an instance of the str class, and every list is an instance of the list class. Calling a class, much as you call int or float on something, builds a new instance of it. In this lesson you stop borrowing other people's classes and write one of your own. The machinery underneath is the machinery you have already been using all along.
