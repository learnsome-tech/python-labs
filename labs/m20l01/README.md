## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### Make a class of your own

1. Write a class Rectangle whose initialiser takes a width and a height and stores both.
2. Make two rectangles of different sizes and print all four numbers.
3. Set a new attribute called colour on one of them, then print vars of both.

> **Hint:** vars on an instance shows the attributes that instance is actually carrying.

## Check yourself

- What is the difference between the Dog class and an instance of Dog?
- When is __init__ called, and what is its first parameter?
- Why does __init__ have no return statement?
- Why does asking a class for an attribute set in __init__ fail?
- Why is the type of one instance the same as the type of another?
