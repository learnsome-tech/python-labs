## Check yourself

- What is the difference between a terminal, a system shell and a Python shell?
- An expression typed in the shell shows an answer; the same line in a file shows nothing. Why?
- What do the letters IDE stand for, and name two things an IDE adds to a plain editor?
- Why does this course start in Idle rather than in a professional editor?
- What does the ending of a file name tell your computer, and what should a Python file end in?
