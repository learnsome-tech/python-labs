## Goal

You can tell a terminal, a shell and a Python shell apart, choose between an interactive shell, an editor with a terminal, and an IDE for a given piece of work, and say what Idle gives you and when to move on from it.

In the lesson: One piece of housekeeping that trips people up before they ever reach Python. A file name usually has an ending after the last dot, called the extension, and it is a label saying what kind of file this is. Text, a photograph, a Python program. Your operating system reads that ending to decide which program should open the file when you double click it. A Python program must be saved with a name ending in dot p y. Save it with the wrong ending and your system will open it in the wrong program. Windows hides these endings by default, which causes real confusion, so turn that setting off before you start.
