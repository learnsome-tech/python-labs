## Goal

You can install your own Python on a Mac by either the python.org installer or Homebrew, leave Apple's system python3 untouched, put yours first on PATH from your zsh profile, and confirm the result with python3 and idle3.

In the lesson: Open a terminal on almost any recent Mac, ask python three for its version, and something answers. That looks as though the job is done. It is not. The interpreter answering is Apple's own, at the path on screen. It arrives with the command line developer tools, it is there so Apple's scripts and other software have an interpreter to call, and it is deliberately conservative: an older release, missing pieces this course needs. Apple's own documentation is blunt: never modify or delete it. So leave it where it is, install a Python of your own beside it, and make sure your shell reaches yours first.
