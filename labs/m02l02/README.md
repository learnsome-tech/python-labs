# m02l02 · Installing Python On A Mac

Module 2: Install Python Properly · lesson 2.2 · Pro · [Open the lesson](https://learnsome.tech/learn/python-course/m02l02)

**Goal:** You can install your own Python on a Mac by either the python.org installer or Homebrew, leave Apple's system python3 untouched, put yours first on PATH from your zsh profile, and confirm the result with python3 and idle3.
