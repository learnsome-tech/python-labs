## Goal

You can install your own Python on a Mac by either the python.org installer or Homebrew, leave Apple's system python3 untouched, put yours first on PATH from your zsh profile, and confirm the result with python3 and idle3.

In the lesson: Route two starts a step further back, because Homebrew has to exist before it can install anything. The install line is on screen, taken from the Homebrew home page: it fetches a shell script and runs it. It asks for your password, prints every directory it is about to create, and waits for you to press return. On a brand new Mac it installs Apple's command line developer tools first. Once brew answers, installing Python is one short line, and upgrading it is one more. That is the appeal: nothing to hunt for, and no installer windows.
