## Goal

You can say what a program is, explain why a computer understands only its own instruction set, trace the path from machine code through assembly to a high level language, and describe the difference between source code on disk and a program running in memory.

In the lesson: Underneath all of it sits the processor, and a processor is far less clever than most people expect. It knows a small, fixed set of operations, built into the silicon when the chip was manufactured. Move a value from one place to another. Add two numbers. Compare two numbers. Jump to a different instruction. That is close to the whole list. Every operation is identified by a pattern of bits, and the row on screen is one real instruction: sixteen ones and zeros telling a certain family of chip to put the value five into a slot. That collection is called the instruction set, and it differs between chip families.
