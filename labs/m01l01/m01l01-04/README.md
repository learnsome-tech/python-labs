## Goal

You can say what a program is, explain why a computer understands only its own instruction set, trace the path from machine code through assembly to a high level language, and describe the difference between source code on disk and a program running in memory.

In the lesson: The first improvement was small in appearance and enormous in effect. Instead of writing the number for an operation, you write a short word for it: move, add, compare, jump. Another program then turns those words back into the numbers. That is assembly language, and the translating program is called an assembler. On screen is that same instruction written in it, and you could now read your own work a week later. Notice carefully what changed and what did not. You are still writing one line for every single thing the processor does, and you are still writing for that processor and no other. What you gained was names. What you did not gain was any distance at all from the hardware.
