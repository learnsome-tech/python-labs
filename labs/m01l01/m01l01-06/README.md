## Goal

You can say what a program is, explain why a computer understands only its own instruction set, trace the path from machine code through assembly to a high level language, and describe the difference between source code on disk and a program running in memory.

In the lesson: Here is one small idea, remember the number five, written at all three levels we have walked through. The top row is what the processor actually receives: nothing but ones and zeros. The middle row is the assembly version, the identical instruction with a name in place of a number. The bottom row is Python. Read upward from the bottom and you watch detail being put back: Python never says which slot, or how wide the number is, or which chip you are sitting at, because the layers underneath decide all of that on your behalf. Read downward from the top and you see the price of living close to the hardware. Every one of those rows is a program. Only the top one is ready to run.
