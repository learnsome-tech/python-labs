**Goal:** You can say what a program is, explain why a computer understands only its own instruction set, trace the path from machine code through assembly to a high level language, and describe the difference between source code on disk and a program running in memory.

## Check yourself

- In one sentence, what is a program, without using the word code?
- Why might a program built for one kind of processor be meaningless to another?
- What problem did assembly language solve, and what problem did it leave untouched?
- What is the difference between source code and a program that is running?
- The power fails while your program runs. What survives, and what is gone?
