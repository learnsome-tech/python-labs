## Goal

You can read and edit an HTML form, make its field names match the names your CGI script asks for, and recognise the text, submit, radio, checkbox and hidden input tags.

In the lesson: This part is optional, for a more elaborate project. You have surely seen radio buttons and check boxes. Here is the middle of the pizza order template, which the pizza script uses as a format string. These three are radio buttons because their type attribute is radio, and they form one group because they share the same name. A radio group allows a unique choice: click one, then another, and the first is dropped.
