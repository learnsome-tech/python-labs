## Goal

You can read and edit an HTML form, make its field names match the names your CGI script asks for, and recognise the text, submit, radio, checkbox and hidden input tags.

In the lesson: In Python string literals, special characters were written with markup beginning with a backslash. HTML has its own version of that idea. The less than and greater than signs have special meaning in markup, so to see those symbols in the browser you need a substitute for the character. Substitutes start with an ampersand and end with a semicolon, as shown. The ampersand is now special itself, so it needs one too. And since runs of white space collapse, there is a character that looks like a space but is not white space.
