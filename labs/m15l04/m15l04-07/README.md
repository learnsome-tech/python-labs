## Goal

You can read and edit an HTML form, make its field names match the names your CGI script asks for, and recognise the text, submit, radio, checkbox and hidden input tags.

In the lesson: This optional section shows where the ideas go next. Data can be stored centrally and shared: serious sites use a database, but a text file on the server is simpler, and that is what the name list page does. Look too at the dump script you have been using. It uses the method on screen, which returns a list of all the values sent under one name, and may have none, one or many elements. You need that when several check boxes share a name.
