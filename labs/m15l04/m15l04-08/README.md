## Goal

You can read and edit an HTML form, make its field names match the names your CGI script asks for, and recognise the text, submit, radio, checkbox and hidden input tags.

In the lesson: Now the appendix, and the raw markup of the simplest example. A plain text editor that colours HTML, such as Sublime Text, is a real help; Mac users can use TextEdit after changing several defaults so it shows source at all. Everything down to the opening body tag is boilerplate, which I will not explain much. The part that matters is inside the title markup, which the browser puts in the tab label. The body contents are the only lines you see on the page. The last two lines are closing the tags.
