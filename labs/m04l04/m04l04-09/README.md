## Goal

You can write assignment statements, explain why the right hand side is evaluated first, and tell a syntax error apart from a name error found while a line is running.

In the lesson: Idle remembers all the variables you have defined at any moment. This is handy when editing. Without pressing Enter, type into the shell just the letter f. Windows users, then hold down the Alt key and press the slash key. Mac users, that combination may give you a funny character, and if so, backspace over it and hold down both the control key and the alt or option key when pressing the slash. Assuming you are following on from the earlier entries, you should see the letter autocompleted to first. Press the combination again and you should see fred. Backspace and edit so you have f and then i, and press it again. You should not see fred this time, since it does not start with those letters. This is particularly useful if you have long identifiers.
