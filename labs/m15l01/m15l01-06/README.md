## Goal

You can explain what a browser and a web server do for each other, read the tags in a simple HTML page, and say which kind of file in this chapter is edited and tested in which way.

In the lesson: On screen is the largest size of heading, holding the text Web Introduction. The heading format is indicated by bracketing that text with markup sequences, one before it and one after. All HTML markup is delimited by tags enclosed in angle brackets, and most tags come in pairs, surrounding the information to be formatted. The end tag has an extra slash, right after the opening angle bracket. Here the letter h stands for heading, and the number gives its relative importance: there is also h two, h three and further, for smaller ones. In the early days people typed all this from memory. You need very little of it.
