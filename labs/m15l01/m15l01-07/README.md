# m15l01-07 · The smallest page worth writing

**Lesson:** [How A Web Page Reaches You](https://learnsome.tech/learn/python-course/m15l01) (lesson 15.1, module 15: Dynamic Web Pages) · Pro  
**Check:** Read along

## Goal

You can explain what a browser and a web server do for each other, read the tags in a simple HTML page, and say which kind of file in this chapter is edited and tested in which way.

In the lesson: This is about the smallest page worth typing. The head section comes first, and the only part of it you care about is the title, which the browser shows in the tab label, not inside the page. Then comes the body, and everything a reader actually sees lives inside it: a heading at the top, then a line of ordinary text. Notice that the ordinary text is not wrapped in anything at all. Plain text sitting between tags gets displayed as it stands. Last come the closing tags, in the reverse order of their openings. Save this with a name ending in dot html, then open it in your browser and you have made a web page.
