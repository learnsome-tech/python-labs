## Goal

You can explain what a browser and a web server do for each other, read the tags in a simple HTML page, and say which kind of file in this chapter is edited and tested in which way.

In the lesson: Documents can be presented in many forms. A simple editor like Idle, or Notepad on Windows, produces plain text: a long string of meaningful characters that all appear in the text you view. Word, Libre Office and Pages display formatting instead, and the syntax each uses to encode that formatting varies enormously. Open an old Word document in a plain text editor and you can find your sentences in there, surrounded by symbols that are unprintable gibberish to a human. Hypertext markup language is very different. Every character in the file is readable, but the markup parts never appear in the browser. They instruct the browser how to format the page.
