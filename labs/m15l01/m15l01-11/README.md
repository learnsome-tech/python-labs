## Goal

You can explain what a browser and a web server do for each other, read the tags in a simple HTML page, and say which kind of file in this chapter is edited and tested in which way.

In the lesson: To make this work on your computer, keep all the web pages in the same directory as the example program localCGIServer, and it is easiest to leave that in the www subdirectory. Looking ahead to the server sections: put your CGI programs in that same directory, and have the server running, started from a directory window and not from inside Idle. Then in the browser address field, the file name must be preceded by http, colon, slash, slash, localhost, colon, eight zero eight zero, slash. On screen you can see that for a page and for a script. Most often a CGI program is named inside a web form and called indirectly by the server.
