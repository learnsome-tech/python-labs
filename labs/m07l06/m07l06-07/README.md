## Goal

You can trace a loop or a nest of function calls by hand, keeping one table row per executed line, and use that table to locate the exact line where a logical error appears.

In the lesson: So far most of the code has been motivated before you saw it, so you had some idea what to expect. Real life is not like that. You will read other people's code, and your own from months ago, without knowing what it was meant to do. Here is such a piece. There are two variables set up before the loop, and inside the loop body both of them change, one of them using the loop variable. There is a single print at the end. Nothing here is new to you, but nobody has told you what it is for.
