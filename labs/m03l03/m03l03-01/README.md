## Goal

You can name four kinds of Python data, call a function with none, one or several parameters, ask type and len about a value, convert between numbers and strings, and re-enter an earlier shell line in Idle.

In the lesson: Python directly recognises a variety of types of data. Here are a few of them, on screen. Numbers: three, six, minus seven, one point two five. Character strings, in quotes: hello, or the answer is, with a colon and a trailing space inside the quotes. Lists of objects of any type, written inside square brackets: a list of four numbers, or a list of three strings. And a special datum meaning nothing at all, whose name is None, with a capital N. That last one surprises people. It is a real value that you can store and pass around; it stands for the absence of data. Keep those four in mind, because almost everything in the next few modules is one of them.
