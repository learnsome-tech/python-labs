## Goal

You can name four kinds of Python data, call a function with none, one or several parameters, ask type and len about a value, convert between numbers and strings, and re-enter an earlier shell line in Idle.

In the lesson: Python has a large collection of built-in functions that operate on different kinds of data to produce all kinds of results. To make a function do its action, parentheses are required. These parentheses surround the parameter or parameters, exactly as in a function in an algebra class. So the general syntax to execute a function is on screen: the function name, then an opening parenthesis, then the parameters, then a closing parenthesis. Remember that shape. Nearly every line you write from here on contains at least one of them, and forgetting the parentheses is one of the most common beginner mistakes: without them you are naming the function rather than running it.
