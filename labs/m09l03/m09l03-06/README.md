## Goal

You can take a slice of a string or list with either bound omitted or negative, predict its length, use find to locate a substring, and drive indices and slices from a loop variable.

In the lesson: A useful string method that uses the ideas of indices and slices is find. It returns the integer index in the string s where the first complete occurrence of the substring sub begins. If sub does not appear at all, find returns minus one, an impossible answer had it been found, so minus one signals that the search failed. Leave start and end out and the search covers the whole string. Give a start and it begins there; give an end and it stops before that index. The index returned is still counted from the beginning of s.
