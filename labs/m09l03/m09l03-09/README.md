## Goal

You can take a slice of a string or list with either bound omitted or negative, predict its length, use find to locate a substring, and drive indices and slices from a loop variable.

In the lesson: Inside the shell you can look up documentation on any method that dir listed. Here you want to refer to the method itself rather than invoke it, so ask for help on s dot find, with no parentheses; parentheses would call the method and ask for help on the answer instead. The documentation uses square brackets for optional elements that take a default value when you leave them out. With no value of the type to hand, use the type name: dir of str, or help on str dot capitalize. And ignore a lone forward slash in a help line; it is not a parameter.
