## Goal

You can install, inspect and remove packages with pip inside an activated environment, pin them in a requirements file that rebuilds the environment anywhere, and read the externally managed environment error correctly.

In the lesson: The standard library is large, but the world has written far more. Public Python packages live in one place, the Python Package Index, and pip is the program that fetches from it and installs. Four commands do nearly everything: install, list, show and uninstall. Two rules before we start. First, activate your environment before installing anything, so the package lands in the project that needs it and nowhere else. Second, remember who publishes there. Anybody may upload a package, and the name they choose is theirs on a first come basis, so installing is a decision, not a reflex. We will come back to how you judge one.
