### Quotient String Return Exercise

1. Create quotientReturn.py by modifying quotientProb.py from the quotient function exercise.
2. The program should accomplish the same thing as before.
3. Change quotientProblem into quotientString, which merely returns the string.
4. Have main print the result of each call to quotientString.

> **Hint:** Addition six is the pattern: build the sentence, return it, and let main do the printing.
