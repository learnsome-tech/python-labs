## Goal

You can name and lay out code the way the rest of the Python world does, let a formatter settle the arguments, read what a linter reports, and write a docstring worth reading.

In the lesson: A formatter is a program that rewrites your file into the standard layout. You do not configure it, you do not argue with it, you run it. The two you will meet are black, which came first and set the tone, and ruff format, which does the same job and is very fast; either is a fine choice, and a project picks one. Install it with pip and give it a file, or a folder, and it reports what it changed. That is the entire interface: one command, one line of output. Most people wire it into their editor so it runs every time they save, and then stop thinking about layout for the rest of their career.
