## Goal

You can build conditions with and, or and not, read their precedence and short circuit behaviour, and return a Boolean expression directly instead of wrapping it in an if else.

In the lesson: Now look back at the bouncing ball. In that program there was an if elif pair where both tests led to exactly the same block. Written like this it takes four lines to say one thing. In English you would not say it that way. You would say: if x is below the low bound or above the high bound, switch the sign of the horizontal step.
