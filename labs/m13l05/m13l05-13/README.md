# m13l05-13 · Two ways to wrap a long condition

**Check:** Read along

## Goal

You can build conditions with and, or and not, read their precedence and short circuit behaviour, and return a Boolean expression directly instead of wrapping it in an if else.

In the lesson: Python already knows that a statement continues to the next line while a bracket is unclosed, which is why long function calls wrap without any fuss. That line had no unclosed bracket, so it needed the backslash instead. The backslash must be the very last character on the line: a stray space after it is an error, and a puzzling one. The alternative on screen is nicer. Put brackets round the whole condition and the wrapping happens by itself.
