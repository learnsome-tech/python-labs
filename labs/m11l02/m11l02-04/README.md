# m11l02-04 · An Oval by its bounding box, and a Text label

## Goal

You can write a complete graphics program with the standard starting lines, build a picture from circles, lines, ovals, text and polygons, take input from mouse clicks, and close the window from inside the picture.

In the lesson: The mouth introduces another kind of object, an oval, which is just an ellipse. Zelle chose to specify it by two opposite corners of the bounding box, the rectangle exactly as wide and as tall as the oval. That rectangle is imagined, not drawn; if you want to see it, construct a rectangle from the same two points. A text object puts writing on the window, and its parameters are the point at the centre of the text and the string itself. The exact coordinates came from trial and error. There is no good way here to predict how big text will be, so you look and adjust.
