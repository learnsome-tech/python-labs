## Goal

You can write a complete graphics program with the standard starting lines, build a picture from circles, lines, ovals, text and polygons, take input from mouse clicks, and close the window from inside the picture.

In the lesson: If you would rather reuse an existing text object for the quitting prompt, prompt close has a second form. Hand it the drawn text object instead of a pair of coordinates, and it puts the prompt into that object, waits for the click and closes. The last three lines then become the single line on screen, and the complete program with that substitution is the second triangle example. One more example is worth knowing exists. If you want regular polygons or stars you need some trigonometry, which is not required anywhere in this tutorial, but the polygons example shows the vertices being worked out.
