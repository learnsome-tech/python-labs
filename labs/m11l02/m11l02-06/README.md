## Goal

You can write a complete graphics program with the standard starting lines, build a picture from circles, lines, ovals, text and polygons, take input from mouse clicks, and close the window from inside the picture.

In the lesson: Prompting, waiting and closing is such a common ending that the tutorial adds a graph win method for it. Here is the same face program with a different last line. Prompt close posts the prompt, waits for the click, and closes the window, so that four line ending shrinks to one line. The only data it needs is where to centre the prompt. You can copy the shape of this program for anything that just draws a picture. One warning: if your program dies while a window is on screen, a dead window lingers, and restart shell from the shell menu tidies up.
