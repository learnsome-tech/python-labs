# m11l02 · Sample Graphics Programs

Module 11: Graphics · lesson 11.2 · Pro · [Open the lesson](https://learnsome.tech/learn/python-course/m11l02)

**Goal:** You can write a complete graphics program with the standard starting lines, build a picture from circles, lines, ovals, text and polygons, take input from mouse clicks, and close the window from inside the picture.

## Check yourself

- What do the first three lines inside main do in every one of these programs?
- Why must a prompt be drawn before the program waits for a mouse click?
- What does getMouse return, and what did the face program do with it?
- How is an Oval specified, and how is a Polygon specified?
- Why does the title bar close button sometimes cause an error?
