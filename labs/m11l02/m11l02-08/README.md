# m11l02-08 · A program that asks the user where to draw

**Check:** Read along

## Goal

You can write a complete graphics program with the standard starting lines, build a picture from circles, lines, ovals, text and polygons, take input from mouse clicks, and close the window from inside the picture.

In the lesson: The next example goes further: rather than the code fixing every coordinate, the program remembers where the user clicked, and uses those places as the corners of a triangle. Run it from your folder window, or with the Python launcher on a Mac, and follow the prompts. Everything above the new line is the standard starting lines. Setting a background colour is a property of the whole window. Then a text object is created as the prompt, and these four calls show most of the ways a text object's appearance can be changed: colour, style and size. The reference pages give the details.
