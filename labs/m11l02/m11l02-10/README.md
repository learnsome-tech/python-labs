# m11l02-10 · A Polygon, and changing text that is already drawn

**Check:** Read along

## Goal

You can write a complete graphics program with the standard starting lines, build a picture from circles, lines, ovals, text and polygons, take input from mouse clicks, and close the window from inside the picture.

In the lesson: Now a very versatile kind of graphics object, a polygon, which may have any number of vertices, handed to it in a list. Notice that set fill and set outline, which we used on a circle, and set width, which we used on a line, all work here too. Then something new. Besides changing the style of a text object, you can change the words themselves: the set text method replaces the prompt with the goodbye message, so no second text object is needed. One more click, and the window closes.
