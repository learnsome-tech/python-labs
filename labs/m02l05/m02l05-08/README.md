## Goal

You can run Python three ways - the shell, a file from a terminal and a file from Idle - and diagnose the six failures that break a fresh install by naming the symptom, the cause and the fix.

In the lesson: Third symptom: something answers, but it is the wrong age. You ask for the version and get an old one, and code that ought to work reports errors on syntax that has been in the language for years. The cause is two Pythons, with the older one earlier on PATH. On screen is that situation on this machine: the copy in the system folder, asked by its full path, reports three point nine point six, while the listing shows both interpreters in search order. The fix is to name the version you want explicitly, or to move the folder you want earlier on PATH.
