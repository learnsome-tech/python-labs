## Goal

You can run Python three ways - the shell, a file from a terminal and a file from Idle - and diagnose the six failures that break a fresh install by naming the symptom, the cause and the fix.

In the lesson: The third way runs that same file from inside Idle. Use the File menu to open the file you just saved, which gives you an editor window rather than a shell. Then choose Run Module from the Run menu, or press the F five key. Idle saves the file for you if there are unsaved changes, restarts the shell so nothing left over from earlier can affect the result, and prints a line of equals signs with the word restart and the name of the file. Under that line is your output. Same file, same interpreter, same two lines.
