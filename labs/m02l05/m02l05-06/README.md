## Goal

You can run Python three ways - the shell, a file from a terminal and a file from Idle - and diagnose the six failures that break a fresh install by naming the symptom, the cause and the fix.

In the lesson: First symptom: nothing is found at all. On a Mac or on Linux the shell says command not found and repeats the name back at you. On Windows the command prompt says the name is not recognised as an internal or external command. The cause is not a broken Python. It is that no folder on your PATH holds a program with that name. The fix has two steps, in this order. Open a fresh terminal first, because one that was already open holds an old copy of PATH. If it still fails, run the installer again and tick the PATH box.
