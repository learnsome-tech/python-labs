## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### Prove your own install

1. In a shell: import sys, then print sys.version and sys.executable
2. Write both answers down in a note inside your Python folder
3. Do it again from a saved file run in a terminal; compare the two
4. If any of the three ways fails, name the symptom before fixing it

> **Hint:** The two attribute names are the ones used in the previous lesson's shell session.

## Check yourself

- What are the three ways to run Python, and which one saves nothing?
- Why must you open a new terminal after changing PATH, rather than reusing the old one?
- A file runs in Idle and fails in the terminal. What is the cause, and the fix?
- Which module is missing when Idle refuses to start, and how do you install it?
- What does missing parentheses in a call to print tell you about where the code came from?
