## Goal

You can run Python three ways - the shell, a file from a terminal and a file from Idle - and diagnose the six failures that break a fresh install by naming the symptom, the cause and the fix.

In the lesson: There are exactly three ways to run Python, and knowing which one you are in saves a great deal of confusion later. The first is the interactive shell: you type one line, it answers, and nothing is kept. The second is a saved file, run from a terminal by naming the interpreter and then the file. The third is that same file, run from inside Idle with the Run Module command. The shell is for questions, files are for programs, and Idle is a convenient way to do both without leaving the editor. We will use all three, in that order.
