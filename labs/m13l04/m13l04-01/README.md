## Goal

You can nest if statements inside loops and loops inside if statements, and read the indentation to see which block belongs to which heading.

In the lesson: The power of a language like Python comes largely from the way basic statements combine. In particular, for statements and if statements can be nested inside each other's indented blocks. Suppose you want to print only the positive numbers from a list. Processing a list suggests a for each loop. But a for each loop runs the same body for every element, and we want the printing to happen for some of them only. That looks like an obstacle until you think about what a computer actually has to do. It cannot see the positive ones at a glance the way your eye can; it must check every number. So there is a consistent action after all: test each number to see whether it should be printed.
