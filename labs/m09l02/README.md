# m09l02 · String Indices

Module 9: Objects And Methods · lesson 9.2 · Pro · [Open the lesson](https://learnsome.tech/learn/python-course/m09l02)

**Goal:** You can pick any character out of a string by index, count either from the front starting at zero or from the right end starting at minus one, and say why an index equal to the length raises IndexError.

## Check yourself

- In the string computer, which character is at index three, and which is at minus three?
- If a string has length twelve, what is the index of its last character?
- Why does asking for the character at index equal to the length raise IndexError?
- Why does backward indexing start at minus one rather than minus zero?
- What does the expression it at index one give for the string horse, and why is that surprising?
