## Goal

You can pick any character out of a string by index, count either from the front starting at zero or from the right end starting at minus one, and say why an index equal to the length raises IndexError.

In the lesson: A string is a sequence of smaller components, the individual characters, and it is often useful to deal with parts of a string rather than the whole thing. Python indexes the characters in a string, starting from zero. So for the word computer, the letter c sits at index zero, o at index one, m at index two, and so on until r at index seven. The table on screen lines the characters up against their index numbers, and it is worth reading across it once slowly. Each index is associated with one character, and you reference an individual character much as you would look something up in a dictionary: the name of the string, then square brackets, then the index you want.
