Lesson `m07l01` · [Watch](https://learnsome.tech/courses/python-course/watch?lesson=m07l01)

## Exercise 1: Number Dictionary Exercise

1. Write a tiny program numDict.py with keys 'one', 'two', 'three' and 'four'.
2. Give each key the matching numerical value 1, 2, 3 or 4, of type int, not a string.
3. Include code that tests it: reference several definitions and print the results.

> **Hint**: The values in a Python dictionary are not required to be strings.
