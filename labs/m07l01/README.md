## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### Number Dictionary Exercise

1. Write a tiny program numDict.py with keys 'one', 'two', 'three' and 'four'.
2. Give each key the matching numerical value 1, 2, 3 or 4, of type int, not a string.
3. Include code that tests it: reference several definitions and print the results.

> **Hint:** The values in a Python dictionary are not required to be strings.

## Check yourself

- What is the difference between a key and a value in a Python dictionary?
- Which side of an assignment makes an entry, and which side fetches one?
- What happens when you ask a dictionary for a key it does not have?
- Why must a key be of an immutable type, when the dictionary itself is mutable?
