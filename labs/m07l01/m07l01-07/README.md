## Goal

You can create a dictionary, add entries to it, look values up by key, recognise the KeyError a missing key raises, and test for a key with in.

In the lesson: We could also use the dictionary more extensively. The example program spanish two a is the same as the last one except for the main function, which is on screen. The top of the file, the createDictionary function, is unchanged, and the call to main is still at the bottom. Each of these two print calls builds one string by concatenating literal pieces with values fetched from the dictionary. Look at how much quoting, joining and comma counting that takes for two lines of output. It prints the count in Spanish, and then the colours in Spanish. Try it, and check that it makes sense. Hold on to how fiddly the code looks, because the next module replaces it with something far more readable.
