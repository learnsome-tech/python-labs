# m07l01-03 · Square brackets do two different jobs

## Goal

You can create a dictionary, add entries to it, look values up by key, recognise the KeyError a missing key raises, and test for a key with in.

In the lesson: To refer to the definition for a word, you use the dictionary name and follow it by the word inside square brackets. This notation can be used in two places. On the left hand side of an assignment it makes, or remakes, a definition. The first line on screen makes an entry in our spanish dictionary for hello, with the definition hola. Used in an expression, as inside the print calls, the earlier definition is retrieved instead. The second line on screen retrieves the definition for red, which is rojo. The same notation, two jobs, and which job you get depends only on which side of the equals sign it stands.
