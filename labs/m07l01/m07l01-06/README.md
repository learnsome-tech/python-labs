## Goal

You can create a dictionary, add entries to it, look values up by key, recognise the KeyError a missing key raises, and test for a key with in.

In the lesson: The rest of the file is the main function and the call that starts everything. To remember the dictionary returned to main, it needs a name. That name does not have to match the name used inside createDictionary, and here the descriptive word dictionary is used instead. The two look-ups then work exactly as before, through the new name. Run it and the shell prints dos and rojo, the same two lines the first version gave. So the behaviour has not changed at all. What has changed is that making and using are now separate, each with a name that says what it is for, and the making can be reused.
