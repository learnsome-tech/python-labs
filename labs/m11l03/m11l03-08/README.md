## Goal

You can find any graphics method for yourself in the reference, by knowing whether it belongs to every graphics object, to one particular type, or to the window, and you know the additions this tutorial makes to Zelle's package.

In the lesson: The second addition is the ending you have now seen several times. You generally want to keep displaying your window until the user chooses to have it closed. Prompt close posts a prompt, waits for a mouse click, and closes the window, all in one call. There are two ways to call it. If there is no prompt on screen yet, give it the coordinates where the centre of the prompt should go. If there is already a drawn text object you would rather reuse, hand it that object instead. Either way, the click ends the program.
