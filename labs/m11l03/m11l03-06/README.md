## Goal

You can find any graphics method for yourself in the reference, by knowing whether it belongs to every graphics object, to one particular type, or to the window, and you know the additions this tutorial makes to Zelle's package.

In the lesson: The window is not a shape, so it has its own list, and that is the third place worth knowing. You can set a background colour for the whole window. You can ask it how wide and how tall it is, which is how the sample programs centred their prompts. Get mouse waits for a click and hands back the point; check mouse looks for a click but returns straight away, which matters once we write animations. Set coordinates replaces the pixel grid with a scale of your own choosing. And close destroys the window.
