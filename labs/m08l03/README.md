## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### One program, every group

1. Write chapter one dot py using at least one idea from each of the nine groups.
2. Prompt for a name and a number of items, and hold unit prices in a dictionary.
3. Define a function that returns a total, and a main function that prints it.
4. Loop to accumulate the total, and show money to two decimal places.

> **Hint:** Keep the calculation inside a function and the input and output outside it, and play computer on your own code before you run it.

## Check yourself

- In what order does an assignment statement do its two jobs?
- Which arithmetic operator has the highest precedence, and which way does it group?
- What type does the input function always return, and what must you do about it?
- What happens when a function is defined, as opposed to when it is called?
- What do you write inside the braces of a format string to round to three decimal places?
