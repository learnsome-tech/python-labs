## Goal

You can recall, in one sitting, every idea from chapter one: the types and their literals, variables, operators and precedence, strings and formatting, input and output, functions, dictionaries, loops and floats.

In the lesson: Group nine: floats, covered in the last two modules. A literal needs a decimal point to distinguish it from an int. The type approximates a wide range of values but does not dependably store them exactly, even numbers with a simple decimal representation. It has the same operation symbols as the integers, but always with a float result, and mixing an int with a float gives a float. Finally, the skill the summary ends with: playing computer. Number the lines, make a table of the line number and every variable that changes, then follow the order of execution one statement at a time.
