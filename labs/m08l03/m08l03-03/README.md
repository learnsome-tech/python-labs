## Goal

You can recall, in one sitting, every idea from chapter one: the types and their literals, variables, operators and precedence, strings and formatting, input and output, functions, dictionaries, loops and floats.

In the lesson: Group two: names, and the assignment statement. An identifier names a Python object. It may contain only letters, digits and the underscore, it cannot start with a digit, and it is case sensitive. You cannot use a reserved word, and you are not advised to redefine names Python already provides; in the Idle editor you are safe while your names stay black. For multi word names, both conventions on screen are fine: underscores in place of blanks, or camel case. Assignment works in one order only. The right side is evaluated first, using the latest value of every variable in it, and only then is the result attached to the name on the left.
