# Exercises — Several Functions, And Flow Of Control

Lesson `m06l02` · [Watch](https://learnsome.tech/courses/python-course/watch?lesson=m06l02)

## Exercise 1: Poem Function Exercise

1. Write a program poem.py that defines a function which prints a short poem or song verse.
2. Give the function a meaningful name.
3. End the program by calling the function three times, so the verse repeats three times.

> **Hint**: The three calls belong at the bottom, outdented, outside the definition.
