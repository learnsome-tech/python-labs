# m06l02-03 · Swap the calls, change the order

## Goal

You can put several function definitions in one file, predict the order in which the lines are executed, and see how indentation decides what is remembered and what is run.

In the lesson: To prove the point, do swap the last two lines of birthday four so they appear as on screen, and see what happens when you execute the program. Andre is sung to first now, and Emily second. Nothing above those two lines changed. The two definitions are untouched and still appear in the same order as before, Emily first. What changed is the order of the calls, and the calls are what actually run. That is worth sitting with for a moment, because it is the shape of every program you will write from now on. The definitions are a vocabulary, in whatever order you like. The lines outside them are the sentence the interpreter reads.
