## Goal

You can put several function definitions in one file, predict the order in which the lines are executed, and see how indentation decides what is remembered and what is run.

In the lesson: There is one practical difference from the previous version. After execution, if we want to give another round of Happy Birthday to both people, we only need to enter one further call in the Shell, the one on screen. In birthday four we would have had to enter two calls, one per person. That is a small saving here and a large one later, when the main action of a program is a dozen steps rather than two. This is the reason for the convention: the program's top level action has a name, so both a human reader and the Shell can reach it in one word.
