## Check yourself

- What is the difference between a syntax error and a run time error?
- Why can the line reported in a syntax error be later than the line at fault?
- Which line of a traceback do you read first, and why?
- What type does the input function always return, and what trouble does that cause?
- In a traceback with three File lines, what do the upper two tell you?
