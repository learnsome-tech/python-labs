## Goal

You can write a Python program that reads a template page from a file, formats your data into it, writes the result out and opens it in your browser.

In the lesson: Here is the middle of the first example program. Above the top of this screen, line four assigns all of this to a name, contents, opening a triple quoted string with the standard document type declaration; that one line is too wide for this screen. Everything you see now is web page markup living inside an ordinary Python string, copied straight out of the source view of the example page. The closing triple quote ends it. Then the main function does one thing: it calls browseLocal, passing the page text. Notice how little Python there is here. The page is data, and data is something you already know how to build, join, format and store.
