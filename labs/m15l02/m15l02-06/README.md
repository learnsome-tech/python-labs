## Goal

You can write a Python program that reads a template page from a file, formats your data into it, writes the result out and opens it in your browser.

In the lesson: Now consider a different approach. Instead of keeping the page inside the program, put it in its own file. This is that file. It is almost the same markup as before, with the lines broken differently, which makes no difference at all, because in HTML any run of white space is treated the same. And there in the body is the name in braces. It is perfectly legal to create a page in a web page editor with expressions in braces embedded in it. This file is not meant to be viewed by a user, being a template, but do open it in a browser to look at it.
