Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### Quotient Web Exercise

1. Save additionWeb.py or skeletonForWeb.py as quotientWeb.py and make it show a division result
2. Display a full sentence labelling the data, the integer quotient and the remainder
3. Make a template file called quotientTemplate.html and read it into your program
4. You should only need to change the processInput and main functions

> **Hint:** Take the calculations from the quotient string exercise in chapter one; turn in both files.

## Check yourself

- Why is a web page a natural thing for a Python program to build?
- What does the format method with the locals function do to a page template?
- What is the advantage of keeping the template in its own file rather than in the program?
- Why does the addition program convert its input before calculating?
- Which part of these programs will the server version reuse unchanged?
