## Exercise 1: Quotient Web Exercise

1. Save additionWeb.py or skeletonForWeb.py as quotientWeb.py and make it show a division result
2. Display a full sentence labelling the data, the integer quotient and the remainder
3. Make a template file called quotientTemplate.html and read it into your program
4. You should only need to change the processInput and main functions

> **Hint**: Take the calculations from the quotient string exercise in chapter one; turn in both files.
