## Goal

You can use the print function's end keyword parameter, alone or together with sep, to print several things on one line from inside a loop and still finish the line properly.

In the lesson: Start with the ordinary behaviour. The first call is given four separate string values, and print puts a single space between each pair of them, because that is what sep does by default. Then end adds a newline, so the second call begins on a fresh line. Two calls, two lines of output. Keep that picture in mind, because the next screen produces exactly the same two lines of output from four calls to print instead of two, and the only difference is the end keyword.
