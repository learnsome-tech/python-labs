## Goal

You can use the print function's end keyword parameter, alone or together with sep, to print several things on one line from inside a loop and still finish the line properly.

In the lesson: By default the print function adds a newline to the end of whatever it prints, which is why each call starts a fresh line. That newline is not a law of nature. It is the default value of a keyword parameter called end, and its default value is the single newline character. You can set end equal to any string you like. The two most common replacements are the empty string, meaning add nothing at all, and a single blank space. You have already met the other keyword parameter, sep, which controls what goes between the values. If you use both, they may come in either order, but keyword parameters must come at the end of the parameter list.
