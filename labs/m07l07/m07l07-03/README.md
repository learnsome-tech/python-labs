## Goal

You can use the print function's end keyword parameter, alone or together with sep, to print several things on one line from inside a loop and still finish the line properly.

In the lesson: Read this alongside the previous screen. The first call prints two of the words and, because end has been set to a single space, it does not move to a new line. The second call therefore carries on along the same line, and it does the same thing again. The third call leaves end alone, so it takes the default newline and finishes the line off. The fourth call then lands on its own line. The output is identical to the version with two calls. Nothing has been gained here, of course, but this is how you build one line of output from several separate print calls.
