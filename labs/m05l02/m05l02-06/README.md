## Goal

You can read a line from the user with the input function, and convert a string of digits into a number so that arithmetic works instead of concatenation.

In the lesson: Two rules about keyword parameters, because we will use more of them. First, they must be listed at the end of the parameter list, after all the ordinary parameters, with the keyword name, an equal sign, then the value. Second, it is a standard Python convention that the equal sign has no space on either side. This is the only place you are not encouraged to set an equal sign off with spaces, and it is a useful visual signal: an equal sign with spaces is an assignment, an equal sign packed tight is a keyword parameter. We will see another one shortly.
