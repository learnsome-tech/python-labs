## Goal

You can add the Python pieces your Linux distribution leaves out with apt, dnf or pacman, understand why pip refuses to install into the system Python, answer that refusal with a virtual environment, and verify the result with python3 and pip3.

In the lesson: Fedora and its family use dnf, and the names shift slightly: the editor package is python three idle, and the Tk package is python three tkinter, spelled out in full. Fedora is more generous than Debian: pip and the venv module arrive with the interpreter. Arch and Manjaro use pacman, where the package is called python with no number, because on Arch python has meant version three for years; add pip and Tk beside it. The habit worth forming is not memorising these lines, but searching your own distribution's packages before searching the internet.
