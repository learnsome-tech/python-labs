# m02l03 · Installing Python On Linux

Module 2: Install Python Properly · lesson 2.3 · Pro · [Open the lesson](https://learnsome.tech/learn/python-course/m02l03)

**Goal:** You can add the Python pieces your Linux distribution leaves out with apt, dnf or pacman, understand why pip refuses to install into the system Python, answer that refusal with a virtual environment, and verify the result with python3 and pip3.
