## Goal

You can turn a script into a command you can run from anywhere, describe your project in a pyproject file, build and install it, and keep its history in git.

In the lesson: Same project, different problem: keeping its history. Git is the tool, and four commands do almost everything. Init makes the current folder a repository, which adds one hidden folder and changes nothing else. Status shows what git can see; the question marks mean these files are not being tracked yet. Add, with a dot, stages everything for the next save. Commit writes that save into the history with a message describing it, and prints how many files and lines changed. Four commands and one more to look: log with the one line flag prints the history so far, currently a single entry. Nothing has been uploaded anywhere. This is all on your own disk.
