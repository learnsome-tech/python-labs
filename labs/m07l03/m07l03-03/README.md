## Goal

You can update a variable, write a list, generate a sequence with range, and read or write a basic for loop that walks over a list.

In the lesson: Particularly if you did not guess right, it is worth following what happens one step at a time, keeping track of the changes each statement makes. The table on screen does that: one row per line executed, one column per variable, and a dash where a variable is not yet defined. It makes one rule visible. The right side of an assignment uses the values the variables have when the line starts executing, and only then does the name on the left change. That is called playing computer.
