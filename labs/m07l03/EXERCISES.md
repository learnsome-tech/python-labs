# Exercises — Lists, Range And The For Loop

Lesson `m07l03` · [Watch](https://learnsome.tech/courses/python-course/watch?lesson=m07l03)

## Exercise 1: Pattern Loop Exercise

1. Write a two line for-each loop in a file types2.py, with one call to the type function.
2. It must produce exactly the same printed output as types1.py above.
3. Execute both versions to check yourself.

> **Hint**: The elements of the list in the heading are not all of the same type, and you need the loop variable twice in the body.


## Exercise 2: Triple Exercise

1. Save tripleStub.py under the new name triple.py and complete tripleAll.
2. It must print triple each of the numbers in the list nums, one per line.
3. Check what the two calls at the bottom print against the documentation string.

> **Hint**: A for-each loop over nums, with a single print in the body, is all it takes.
