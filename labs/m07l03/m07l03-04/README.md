## Goal

You can update a variable, write a list, generate a sequence with range, and read or write a basic for loop that walks over a list.

In the lesson: Lists are ordered sequences of arbitrary data. They are the first kind of data we have met that is mutable: the length can change and elements can be substituted. We delay the discussion of changing lists until we know more about objects. Read the examples on screen. The basic format is a square bracket enclosed, comma separated list of arbitrary data. Three colour names. Six odd numbers. A mixture of strings and negative numbers. The empty list, with nothing between the brackets. And a list containing three elements, each of which is itself a list.
