## Goal

You can update a variable, write a list, generate a sequence with range, and read or write a basic for loop that walks over a list.

In the lesson: Loops are one of the most important features in programming. The syntax is simple; using them creatively to solve problems is the real challenge. One way to simplify the learning curve is to name common patterns. The simplest is the for each pattern: for each element of the sequence, do the same sort of thing with it. Recall these three lines from the mad lib program. Each does the same thing except for the string used as the cue. The alternative below collects those varying pieces of data into the list in the heading, and uses one variable, cue, in the body.
