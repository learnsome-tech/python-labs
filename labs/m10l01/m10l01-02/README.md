## Goal

You can write a function that scans a format string and returns the list of cues embedded in it, and you can follow the creative process that produced it.

In the lesson: We begin with the shape of the thing we want and nothing else. The definition heading names the function getKeys and gives it one parameter, the format string with the cues embedded in it. Underneath goes the documentation string, saying what goes in and what comes back out: a list containing all the keys from the format string. Then a placeholder comment, because the body is not written yet. Writing this much first is not a waste of time. It settles the name, the input and the output, so every decision after it has something to aim at. If you cannot write the documentation string, you do not yet know what the function is for.
