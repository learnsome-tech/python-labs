## Goal

You can write a function that scans a format string and returns the list of cues embedded in it, and you can follow the creative process that produced it.

In the lesson: Now we can write the plan down. Some of it is real Python and some is still English, and that mixture is called pseudo-code. The list is created empty before the loop and appended to inside it, which is the accumulation pattern we already know. The counting line, the loop heading, the slice line and the append line are all settled. Two things are not: the initialisations before the loop, and the line that finds the start and end of the next key. Look at what this plan has bought us. One big vague problem has turned into a single precise question: how do we find the next pair of braces?
