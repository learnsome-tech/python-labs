## Goal

You can write a function definition with def, an indented body and a call, and explain why defining a function is not the same as running it.

In the lesson: Now we give the song a name. The Python keyword def, short for define, starts a function definition. The heading has four parts: the word def, then the name of the function, then a pair of parentheses, then a colon at the end. Here the name is happyBirthdayEmily. Everything that belongs to the function follows as an indented body, indented by a consistent amount. Two or four spaces are the common conventions, and the interpreter cares only that you are consistent. Now load this file in Idle and run it. Nothing happens. Nothing is printed at all, and that is correct. The definition defines the meaning of the name and does nothing else. The statements inside are not executed as Python first passes over the lines. Python merely remembers them, in the way it remembers the value of a variable you assigned.
