## Goal

You can write a function definition with def, an indented body and a call, and explain why defining a function is not the same as running it.

In the lesson: When new syntax turns up in this course, you get both a specific example and a general template. In a template the typeface tells you the category of each part. Text in typewriter font is written out exactly as you see it. Emphasised text marks a place where you may put any expression you like. Bold text marks a place where you may put any identifier you choose. Ordinary words are a description of what belongs in that position, without giving the syntax. On screen is a template for an assignment statement: a bold variable name, then the specific equals symbol, then an emphasised expression. Underneath it is the template we need next, for a function definition heading. Learn to read templates this way now, and they will serve you for the rest of the tutorial.
