### Birthday Function Exercise

1. Change birthday7.py and save it as birthdayMany.py.
2. Add a function call, but not another function definition, so Maria gets a verse too.
3. Also print a blank line between verses.
4. Do that either by adding a print line to the definition, or between all the calls.

> **Hint:** Emily, Andre and Maria share one definition; only the actual parameter changes.

## Check yourself

- What is the difference between a formal parameter and an actual parameter?
- What exactly happens to person when happyBirthday is called with the string Andre?
- Why do the calls in birthday seven not run until the last line of the file?
- In birthday who, why need userName and person not have the same name?
- When you read a traceback, why look at more than the last line?
