## Goal

You can write a function with a parameter, call it with different arguments, and explain how a formal parameter is given the value of an actual parameter at the moment of the call.

In the lesson: Here is the mechanism. When the call is made, Python associates the formal parameter name person with the actual parameter data, exactly as an assignment statement would. In the first call that data is the string Emily, so inside the body person has the value Emily, and the third line of the song prints as you see at the top of the screen. We return to the end of line nine, then line ten calls the function again with the string Andre, person now has that value, and the third line prints as you see underneath. Be sure you completely understand birthday six and this sequence. It illustrates ideas that many people miss on a first reading. Defining is instructions to be remembered, with formal parameter names. Calling substitutes actual values and runs the code.
