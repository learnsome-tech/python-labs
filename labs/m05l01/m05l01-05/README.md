## Goal

You can open, write, save and run a Python program file in the Idle editor, and you can tell program code apart from Shell text.

In the lesson: Now write a program from scratch. With a Python file in the foreground, go to the File menu and select New File. That gives you a conventional text editing window, with the mouse, cut and paste, and a few special options for Python. Type this single line into the editor window, not into the Shell window. That is the whole program. Save it with File, then Save, and enter the file name hello dot py. Program files should always be given a name ending in dot p y; with no extension, that one is assumed. There is also Save As, which switches Idle to editing the new name, and Save Copy As, which leaves you editing the original. Careful: it is the foreground window that gets saved.
