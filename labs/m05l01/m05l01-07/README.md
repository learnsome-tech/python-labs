# m05l01-07 · Program code is not Shell text

## Goal

You can open, write, save and run a Python program file in the Idle editor, and you can tell program code apart from Shell text.

In the lesson: It is easy to confuse the Shell and the edit windows, so keep them straight. The hello program is just the one printing line you typed into the edit window and saved. When you ran it, the results appeared in the Shell: first the restart notice, then the one line of output saying hello, then a further Shell prompt. What is on screen now is that Shell transcript, and it is not a program. Those triple angle bracket prompts have no place in a Python program file.
